LutLayer

Section titled “LutLayer”

実体: griffith_logic.layers.lut.LutLayer（クラス）

N入力LUT（Look-Up Table）層。

一般化LUTの数式: y = Σ_{k=0}^{2^N-1} f(W)[k] × Π_{j=0}^{N-1} (x_j if bit(k,j)=1 else 1-x_j)

パラメータ化方式: - ‘softmax’: f = softmax（エントリ間が競合、合計1）— DLGN方式 - ‘independent’: f = ρ（各エントリ独立、合計≠1）— BinaryBrain方式。 論文 arXiv:2510.03250 の IWP (Eq.11) と数学的に同一 （ω_k = ρ(Ω_k) をエントリ確率とする一般化LUT） - ‘iwp’: 入力ごとに1パラメータのリテラル積（単一ミンターム）。 論文 arXiv:2510.03250 の IWP とは別物（16ゲート中4種しか 表現できない）。論文のIWPは ‘independent’ に相当する - ‘raw’: 重みを直接[0,1]で保持 — BinaryBrain方式 - ‘warp’: Walsh-Hadamard基底（制約なし実数、Gumbel smoothing）— WARP方式

N=2でdifflogicの16ゲートsoftmax加重と等価。 N=4,6でBinaryBrainのLUT4/LUT6と同じ表現力。 N=4,6ではwarpパラメータ化が安定学習に推奨（Gerlach et al., 2025）。

LTTLayer

Section titled “LTTLayer”

実体: griffith_logic.layers.ltt.LTTLayer（クラス）

線形閾値ゲート層: 二値入力 → n 入力の閾値関数 × out_dim → 二値出力。

引数

  • in_dim — 入力ビット数
  • out_dim — ゲート数 = 出力ビット数
  • n_inputs — ゲートあたりの入力数 n(既定 6 = 先行実験)
  • connections — ‘random’(均衡乱択)/ ‘unique’ / ‘learnable’(LearnableMapping)/ (n_inputs, out_dim) の int Tensor
  • ste — 代理勾配 ‘clip’(既定)/ ‘identity’ / ‘sigmoid’
  • ste_scale — 代理勾配の温度 s(既定 1.0)
  • clamp — 訓練時の forward ごとに w, b を [−1, 1] へ clamp(既定 True)
  • lm_tau — connections=‘learnable’ の LearnableMapping の逆伝播 softmax 温度
  • device — 配置先

GroupSum

Section titled “GroupSum”

実体: griffith_logic.group_sum.GroupSum（クラス）

出力ニューロンをkクラスにグループ化して合計する層。 最終層のLUT出力を分類ロジットに変換する。

クラス割当 assign(内部調査リポジトリ先行実験の GroupSum): contig — ニューロン i → クラス i // m(連続ブロック。difflogic / 従来の既定) stride — ニューロン i → クラス i mod k(k 飛び。conv 頭部で前層の局所性が クラスに偏る「連続割当の罠」を避ける) IR では group_sum ノード自体は contig のまま、stride は手前に (m, k) → (k, m) の転置(permute / 恒等 lut_layer)を挟んで表す (export/extract.py。SpatialGroupSum の抽出と同型)。

判定バイアス bias(内部調査リポジトリ先行実験の 2 クラス判定則 s1 > s0 + t): クラスごとの定数をクラス和に足してから τ で割る(logits = (Σ + bias) / τ)。 NID の s1 > s0 + t は bias = [t, 0](または [0, −t])。IR では group_sum.params.bias(整数、省略 = 全 0)で運び、simulate が足す。HDL 生成は未対応 (validate(target=‘hdl’) が bias ≠ 0 を拒む。FPGA 側の終端部品か後続タスク)。

get_random_connections

Section titled “get_random_connections”

実体: griffith_logic.core.connections.get_random_connections（関数）

ランダムにN個の入力を各出力ニューロンに割り当てる。 全入力が少なくとも1回使われることは保証しない。

注意(先行実験 T3 で確認した実測の性質): 本実装は randperm(n_inputs·out_dim) % in_dim を randperm(in_dim) で貼り替えるので、 各入力の使用回数は floor / ceil(n_inputs·out_dim / in_dim) の 2 値しか取らない (= 均衡している)。したがって n_inputs·out_dim >= in_dim のときは 被覆率が常に 100% で、get_permutation_connections と同じ分布になる (in=9216 / out=8000 / n=2 で被覆 9216/9216、使用回数 1 回が 2432・2 回が 6784)。 「各スロットを独立一様に引く」無制約の乱択が要るときは get_uniform_random_connections を使う(同条件で被覆率 約 82%)。

引数

  • in_dim — 入力次元数
  • out_dim — 出力ニューロン数
  • n_inputs — 1ゲートあたりの入力数
  • device — 出力テンソルのデバイス
  • generator — 乱数生成器(None ならグローバル RNG = 従来動作と bitwise 不変)

戻り値

indices: (n_inputs, out_dim) int64 テンソル

get_unique_connections

Section titled “get_unique_connections”

実体: griffith_logic.core.connections.get_unique_connections（関数）

すべての入力が少なくとも1回は使われることを保証する接続。 difflogicのオフセットペアリングアルゴリズムをN入力に一般化。

N=2の場合はdifflogicと同一のアルゴリズム:

  • offset=0: (0,1), (2,3), (4,5), …
  • offset=1: (1,2), (3,4), (5,6), …
  • offset=2: (0,2), (1,3), (2,4), …
  • out_dim個のユニークなペアが揃うまで継続

N>2の場合: 各入力スロットに対して独立にオフセットペアリングを適用。

戻り値

indices: (n_inputs, out_dim) int64 テンソル

get_rot_connections

Section titled “get_rot_connections”

実体: griffith_logic.core.connections.get_rot_connections（関数）

rot 規則の規則配線(2入力固定)。

社内先行実験 wiring.py の rot_layer と同一定義:

「ずらし量 s」が入力の平坦化順の中で幾何的な意味を持つ配線 (例: 先行実験 CIFAR サーモメータ順 ((c*32+row)*32+col)*3+t では s=3 が右1画素、s=96 が1行下)。乱数を使わないので完全に決定的。

歩進 step(既定 1 = 従来の rot と bitwise 同一)は内部調査リポジトリ先行実験の rot2((g·r + s) mod W_in。conv 頭部で前層の幅 > 出力幅のとき、隣接ゲートを r ずつ離して前層の出力をデッドにしない)。計算型 overlay では歩進定数を V から r·V に替えるだけなので、IR・HDL・overlay の形は変わらない。

引数

  • in_dim — 入力次元数
  • out_dim — 出力ニューロン数
  • s_a — 第1入力のずらし量(負値・in_dim超も可。剰余で丸める)
  • s_b — 第2入力のずらし量
  • device — 出力テンソルのデバイス
  • step — 歩進 r(ゲート g の基準位置 g·r。既定 1)

戻り値

indices: (2, out_dim) int64 テンソル

get_permutation_connections

Section titled “get_permutation_connections”

実体: griffith_logic.core.connections.get_permutation_connections（関数）

置換(均衡全射)配線(2入力固定)。

社内先行実験 wiring.py の perm_index / perm_layer と同じ意味の 配線で、2·out_dim 個の入力スロットを in_dim 個のソースが等回数ずつ埋める。 各ソースの使用回数(= fan-out)は floor(2·out_dim / in_dim) と ceil(2·out_dim / in_dim) の 2 値しか取らないので、 「構造的に未参照なソース」が原理的に出ない(2·out_dim >= in_dim のとき)。

実装: q, r = divmod(2·out_dim, in_dim) として、arange(in_dim) を q 回 タイルしたものに「ランダムに選んだ r 個のソース」を足してプールを作り、 シャッフルしてから前半を idx_a、後半を idx_b にする。 → 使用回数はちょうど q 回か q+1 回で、+1 になるソースの選び方に偏りが無い。

先行実験の原実装は idx_a / idx_b を独立に均衡全射として引き、 余りをタイルの切り詰めで決める。それは (a) in_dim <= out_dim を前提にしており (wiring.py の docstring に「w_in > w_out は本実験では発生しない… その場合は画素 0..w_out-1 しか使われない。要再設計」と明記)、 先行実験の層0(9216 -> 8000)では条件を満たさない。(b) 切り詰めなので 余りが常に先頭のソース(画像の左上側)に偏る。本実装は 2·out_dim スロットをまとめて均衡させ、余りを乱択することでどちらも避ける。 in_dim == out_dim(r = 0)では原実装と同じく各ソースがちょうど 2 回使われる。

idx_a[g] == idx_bgは原実装と同じく排除しない (縮約器が「同一入力」規則で数える対象として残す)。

注意: 2·out_dim < in_dim のときは鳩の巣原理で全ソースは使えない (q=0, r=2·out_dim なので「ランダムに選んだ 2·out_dim 個のソースを 1 回ずつ」)。

引数

  • in_dim — 入力次元数
  • out_dim — 出力ニューロン数
  • generator — 乱数生成器(Noneならグローバル RNG)
  • device — 出力テンソルのデバイス

戻り値

indices: (2, out_dim) int64 テンソル

get_stretched_rot_connections

Section titled “get_stretched_rot_connections”

実体: griffith_logic.core.connections.get_stretched_rot_connections（関数）

引き伸ばし rot 配線(2入力固定、先行実験 SR 腕)。

rot は基準位置が g(1 ずつ)なので out_dim < in_dim では入力の先頭側 out_dim + max(s_a, s_b) 本しか読まない。本配線は基準位置だけを in_dim / out_dim 刻みに引き伸ばし、対の作り方(ずらし量 s_a / s_b)は rot のまま残す:

丸めは四捨五入(半整数は切り上げ)を整数演算で行う:

Python 組み込みの round は偶数丸めなので半整数でずれる(例 in=4, out=8 の g=1 は本定義が 1、round(0.5) は 0)。浮動小数を使わないので デバイス・環境によらず完全に決定的。

性質:

  • in_dim == out_dim では base[g] = g となり get_rot_connections と bitwise 一致する。
  • 対の差は rot と同じく一定: (idx_b - idx_a) ≡ (s_b - s_a) (mod in_dim)。 平坦化順が幾何を持つ符号化(先行実験 CIFAR サーモメータ順)では、 s_b - s_a = 93 のような「右1画素と1行下」の局所性が保たれる。
  • 先行実験層0(in_dim=9216, out_dim=8000, s_a=3, s_b=96)の被覆率は 9216/9216 = 100.0%(実測値。tests/l1_math/test_connections_generators.py の test_exp100_layer0_covers_every_input が assert する)。 同条件の rot は 8093/9216 = 87.81% しか読まない。 使用回数は 1 回が 2432 本・2 回が 6784 本で、未参照の入力は無い。
  • 被覆率 100% は一般には保証しない。基準位置は in_dim / out_dim 刻みで 飛ぶので、比が整数のときは s_b - s_a の剰余次第で穴が残る (例 in=16, out=8 は base が偶数のみ。s_a=3, s_b=5 だと奇数しか読まず 50%、 s_a=3, s_b=6 なら 100%)。in_dim / out_dim が整数でない実験条件 (9216/8000 = 1.152)では基準位置の増分が 1 と 2 の混在になり穴が埋まる。 使う前に connection_stats で被覆率を確認すること。

引数

  • in_dim — 入力次元数
  • out_dim — 出力ニューロン数
  • s_a — 第1入力のずらし量(負値・in_dim超も可。剰余で丸める)
  • s_b — 第2入力のずらし量
  • device — 出力テンソルのデバイス

戻り値

indices: (2, out_dim) int64 テンソル

get_uniform_random_connections

Section titled “get_uniform_random_connections”

実体: griffith_logic.core.connections.get_uniform_random_connections（関数）

無制約の一様乱択配線(各スロットを独立に一様サンプル、先行実験 RAND 腕)。

sort_model_wiring

Section titled “sort_model_wiring”

実体: griffith_logic.core.sort_wiring.sort_model_wiring（関数）

各LutLayerの出力ニューロンを第1入力インデックス昇順にrenumberする。

モデル等価な置換(forward出力・backward勾配は対応付けの上で不変)。 ゲートを読み出し先の番地順に並べ、gatherのメモリ局所性を改善するのが目的。 融合CUDAカーネルを使う学習では速度への効果は小さい(実測0.5〜0.7%)。

optimizer構築前に呼ぶのが基本。構築後(学習途中を含む)に呼ぶ場合は optimizer= を渡すこと。Adam等のモーメント(weightsと同じ形の状態)を同じ 置換で並べ替える。渡さないとモーメントが別のニューロンに適用されたまま 学習が続く(本関数からはoptimizerの存在を検出できないため、呼び出し側の 責務となる)。

引数

  • model — nn.Sequential(必要ならFlatten等の非LutLayer要素も可)。 連続するLutLayer列(すべてwiring=‘fixed’) + 末尾GroupSum(あれば) という構造のみ対応。
  • inplace — Trueなら引数のmodelを直接書き換えて返す(既定)。 Falseならdeepcopyしたモデルを書き換えて返し、元のmodelは 変更しない(before/afterの比較テストや、フォールバック用に 元modelを残したい呼び出し元向け)。
  • optimizer — modelのパラメータを持つoptimizer(構築後に呼ぶ場合)。 per-parameter状態をweightsと同じ置換で並べ替える。 inplace=Falseとは併用できない(コピー側のパラメータはoptimizerが 持つパラメータと別物のため)。

戻り値

置換適用後のモデル(inplace=Trueなら引数と同一オブジェクト)。

例外

UnsupportedWiringError: - modelがnn.Sequentialでない - LutLayerがSequential内で連続していない - いずれかのLutLayerがwiring=‘learnable’ - 最終LutLayerの出力次元がGroupSumのクラス数で割り切れない (LutLayer/GroupSum自体の不整合。通常は起こらない) ValueError: optimizer と inplace=False を同時に指定した

get_butterfly_connections

Section titled “get_butterfly_connections”

実体: griffith_logic.core.connections.get_butterfly_connections（関数）

循環 radix-n バタフライ 1 段(内部調査リポジトリの先行実験の BF6 / BF4 の bf6_stage)。

Cooley-Tukey の radix-n 段を、幅が n の冪でないときは mod で巻き戻した形。 層 s(1 始まり)で stride = n^(s−1) を使うと、k 段で各出力ノード j が { j + t (mod W) : 0 ≤ t < n^k } の連続区間に到達する(n 進数の全表現)。 n^k ≥ W なら全ノードに到達し、gather 段(get_rot_n_connections の shifts 0..n−1、step n)の完全被覆と合わせて全出力が全入力に到達する。 in_dim == out_dim のとき各入力はちょうど n 回読まれる(fan-out 均衡)。

stride · m が mod in_dim で衝突する組合せ(例 in_dim=12, n=6, stride=6)は 同じ入力を複数スロットで読む。必要なら dedupe_connections で潰す (先行実験の build() は常に潰していた)。

戻り値

indices: (n_inputs, out_dim) int64 テンソル

get_local2d_connections

Section titled “get_local2d_connections”

実体: griffith_logic.core.connections.get_local2d_connections（関数）

2D 局所窓(内部調査リポジトリの先行実験の候補 C / L2D6 / L2D4)。

入力 in_dim ビットを「(H, W) 格子のセル × bits_per_cell ビット」と見なす (bit = cell · z + t の feature-major。サーモメータ z 本の画像なら z = bits_per_cell)。 ゲート g の中心セル c_g = prop_map(out_dim, n_cells)(n_cells = in_dim / z)、 (y, x) = divmod(c_g, W)。オフセット k = (dx, dy) ごとにトーラスで隣接セルを取り、 格子がセル数より大きい分(正方格子の末尾)は mod n_cells で巻き戻す:

grid=None は G = ceil(√n_cells) の正方格子(隠れ層の既定。in_dim == out_dim なら c_g = g で先行実験の隠れ層式に一致)。画像の層 0 は grid=(H, W) を渡す: 先行実験 L2D6 層 0 = grid (28, 28)、z=3、offsets [(1,0),(0,1)](右隣・下隣の 2 画素 × 3 bit)、先行実験 L2D4 層 0 = z=4、offsets [(0,0)](自画素の 4 bit)。

引数

  • in_dim — 入力次元数(bits_per_cell の倍数)
  • out_dim — 出力ニューロン数
  • offsets — (dx, dy) の列。ring_offsets / local2d_offset_schedule が作る
  • grid — (H, W)。None なら正方格子
  • bits_per_cell — セル当たりのビット数 z
  • device — 出力テンソルのデバイス

戻り値

indices: (len(offsets) · bits_per_cell, out_dim) int64 テンソル
