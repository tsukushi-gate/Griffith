ThermometerEncoder

Section titled “ThermometerEncoder”

実体: griffith_logic.encoding.thermometer.ThermometerEncoder（クラス）

Thermometer符号化層。

引数

  • bits — 特徴あたりのビット数 z(しきい値の個数)
  • mode — ‘uniform’(等間隔) | ‘distributive’(経験分位点)
  • input_bits — IR 化(export_ir)するときの入力の量子化ビット数 B。 None(既定)では境界(IR の外)のまま。指定すると抽出器が特徴ごとの B ビット符号 c(LSB 先頭、位置 d·B + j)を入力とし、実数 q = c / (2^B − 1) (ToTensor の uint8 → [0, 1] と同じ)としてしきい値比較を B 入力 lut_layer の 真理値表に焼く。torch の forward は従来どおり実数 q を受ける

属性

  • thresholds — (bits, n_features) しきい値(fit後に確定)

このAPIを使っている例

  • DWN — 温度計符号化とn入力LUTで解くMNIST — examples/16_dwn.py

DWNLayer

Section titled “DWNLayer”

実体: griffith_logic.layers.dwn.DWNLayer（クラス）

DWNのLUT層: 二値入力 → n入力LUT×n_luts → 二値出力。

引数

  • in_bits — 入力ビット数
  • n_luts — LUT(RAMノード)数 = 出力ビット数
  • n_inputs — LUTあたりの入力数 n
  • mapping — ‘random’(固定ランダム接続) | ‘learnable’(Learnable Mapping)
  • efd — EFD係数 ‘paper’(1/(H+1)) | ‘official’(α·β^H) alpha, beta: efd=‘official’の係数(None時は公式既定値)
  • ste — 出力を{0,1}に二値化する(公式既定値True)
  • clamp_luts — 訓練時に毎forwardでテーブルを[−1,1]へclamp(公式既定値True)
  • lm_tau — Learnable Mappingのsoftmax温度

このAPIを使っている例

  • DWN — 温度計符号化とn入力LUTで解くMNIST — examples/16_dwn.py

LearnableMapping

Section titled “LearnableMapping”

実体: griffith_logic.layers.dwn.LearnableMapping（クラス）

入力→LUTの接続を勾配で学習する層。

訓練中は重み行列 W ∈ ℝ^{in×out} を保持し、forwardは既定で x_{argmax(W[:,i])} のハード選択(推論時のオーバーヘッドなし)。

漸進配線ハード化(SparseLUT arXiv 2503.12829の2フェーズを適応): forward_mode=‘soft’ では x @ softmax(W/tau_soft, dim=0) のsoft混合 forwardになる(純autograd、選択の不連続ジャンプ無し)。 ProgressiveWiringSchedulerがtau_softを幾何減衰させ、訓練後半で forward_mode=‘hard’(従来のargmax+STE)へ切り替える。 hard選択の配線学習が崩壊したことへの対策レバー。 evalは常にhard argmax(forward_modeは訓練時のみ参照)。

引数

  • in_features — 入力ビット数 P
  • out_features — 出力ビット数 Q(= LUT数 × LUT入力数)
  • tau — backwardのsoftmax温度(公式既定値 0.001)

DWNClassifier

Section titled “DWNClassifier”

実体: griffith_logic.models.dwn.DWNClassifier（クラス）

Thermometer符号化 + DWN多層LUT + popcount集約の分類器。

引数

  • in_features — 実数値入力の特徴数 D
  • n_classes — クラス数 k
  • layer_widths — 各DWNLayerのLUT数(最終層はn_classesで割り切れること)
  • bits — Thermometer符号化のビット数/特徴
  • encoder_mode — ‘uniform’ | ‘distributive’(distributiveはfit_encoder必須)
  • n_inputs — LUTあたりの入力数 n
  • mapping — 第1層の接続方式 ‘random’ | ‘learnable’(第2層以降はrandom固定)
  • efd — EFD係数 ‘paper’(1/(H+1)) | ‘official’(α·β^H)
  • tau — GroupSumの温度(公式既定値 1/0.3)

このAPIを使っている例

  • DWN — 温度計符号化とn入力LUTで解くMNIST — examples/16_dwn.py

ConditionalSum

Section titled “ConditionalSum”

実体: griffith_logic.models.llvit.ConditionalSum（クラス）

Dense encoded-value summation after binary LUT outputs.

During training this uses fp32 encoded values. When use_quantized_eval=True and the module is in eval mode, the encoded values are symmetrically quantized to int4-style levels and dequantized for forward execution.
