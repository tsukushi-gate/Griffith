入門2. PyTorchでMLPを組む

前ページの道具立てのまま、手書き数字(MNIST 20x20)へスケールさせる。 nn.Linear を3枚重ねただけの MLP が test accuracy 0.95 に届く。

このページの見どころは 「実数の重みはどこにあるのか」 が絵になること。 1層目の重みは入力と同じ 400 次元なので、20x20 に並べ直すと そのニューロンが探している形がそのまま見える。次のページでは、 この重みが丸ごと論理ゲートの真理値表へ置き換わる。

このページについて

所要時間の目安: 約8分 / 実行環境: CPU のみ(GPU 不要) 元スクリプト: examples/25_pytorch_mlp.py 手元で試す: notebooks/25_pytorch_mlp.ipynb(このページと同じ内容の未実行ノートブック。uv run --group docs jupyter lab notebooks/ で開ける) コード出力はすべて 実際に実行した結果をそのまま埋め込んでいます。

▶ Colabで開く(リポジトリ公開後に有効化)

PyTorchで小さなMLPを組んで手書き数字を読む(入門コース 2/3)。

前のページで見た「テンソル・自動微分・nn.Module・学習ループ」を、 そのまま実データへ持っていく。題材は手書き数字 MNIST を 20x20 に切り詰めたもので、 入力は 400 個の数(ピクセルの明るさ)、出力は 0〜9 の 10 クラス。

書くものは3つだけで、すべて前ページと同じ道具である。

  • nn.Linear を3枚重ねた MLP(多層パーセプトロン)
  • F.cross_entropy による損失
  • opt.zero_grad() → backward() → step() の学習ループ

このページの主題は精度そのものではなく、**「実数の重みはどこにあるのか」**を 目で見て掴むことにある。1層目の重みは入力と同じ 400 次元なので、 20x20 の画像として並べ直すと **「そのニューロンが探している形」**がそのまま絵になる。 次のページ examples/26_mlp_to_dlgn.py では、ここで見た重みが丸ごと 論理ゲートの真理値表へ置き換わる。

実行: uv run python examples/25_pytorch_mlp.py 期待結果: test accuracy 0.95 前後(2隠れ層の MLP・CPUで10秒ほど)

準備: import と乱数種

Section titled “準備: import と乱数種”

使う道具は入門1とまったく同じで、増えたのはデータの読み込みだけ。 load_mnist20x20 は本ライブラリが同梱する MNIST ローダで、 28x28 の画像から黒い縁を落として 20x20 = 400 画素にしたものを返す。

400 画素にするのは difflogic 論文の公式レシピに合わせるためで、次ページの 論理ゲート版と同じ入力を使うことで比較が公平になる。

ハイパーパラメータ(学習の前に人間が決める数)

Section titled “ハイパーパラメータ(学習の前に人間が決める数)”

ハイパーパラメータとは、学習では動かず人間が事前に決める設定値のこと (学習で動くのが「パラメータ」= 重み)。ここでは隠れ層の幅・イテレーション数・ ミニバッチサイズ・使用枚数の4つを、CPU で10秒に収まる値に絞ってある。

データセット: 手書き数字 MNIST 20x20

Section titled “データセット: 手書き数字 MNIST 20x20”

1枚の画像は 20x20 の画素からなり、それを1列に伸ばして 400次元のベクトルとして モデルへ入れる。各画素の値は 0(白)〜1(黒)の実数である。

binarize_threshold=None を渡して二値化せず、実数のまま扱っている点に注意。 実数 NN は実数入力をそのまま食べられる ── ここが次ページの論理ゲート版で 「ビットに落とす」必要が出てくる箇所になる。

モデル定義: nn.Linear 3枚のMLP

Section titled “モデル定義: nn.Linear 3枚のMLP”

MLP(多層パーセプトロン) とは、nn.Linear と活性化関数を交互に積んだだけの 最も素朴な NN のこと。ここでは 400 → 128 → 64 → 10 と幅を絞りながら3枚重ねる。

なぜ幅を絞るのか ── 前半の層で「画素の集まり」から「線・曲がり」といった 特徴を作り、後半で「その特徴の組み合わせが数字のどれか」を判断する、という 役割分担を素直に書くとこの形になる。最後の10出力はクラスごとのロジット (生のスコア)で、softmax を通せば「その数字である確率」になる。

学習: ミニバッチで回す

Section titled “学習: ミニバッチで回す”

ループの中身は入門1と同一で、違いは1点だけ ── 毎回すべてのデータを使わず、 BATCH 枚だけランダムに取り出して更新する ミニバッチ学習にしている。

なぜミニバッチか ── 20000枚すべてで勾配を計算すると1ステップが重すぎる。 一部だけで計算した勾配は本来の勾配のノイズ入り近似だが、その分ステップ数を 稼げるので、同じ計算時間ならこちらが速く進む。ノイズ自体も局所解から抜ける助けになる。

評価: 学習曲線を読む

Section titled “評価: 学習曲線を読む”

図1: 損失とテスト正解率

Section titled “図1: 損失とテスト正解率”

橙が訓練データの損失(左軸)、緑がテスト正解率(右軸)。2つの軸を重ねているので、 「損失が下がるとき正解率が本当に上がっているか」を1枚で確かめられる。

読み取り: 序盤の数百ステップで損失が急落し、正解率が 0.9 を越える。以降は ゆるやかに 0.95 前後へ張り付く。曲線が1本しかないことに注目してほしい ── 実数 NN では「学習中のモデル」と「使うモデル」が同じものなので、測る精度も1種類でよい。 次ページの DLGN では、ここが soft と hard の2本に増える。

学習された「実数の重み」を見る

Section titled “学習された「実数の重み」を見る”

このページの主題。NN が学習した中身を、数字ではなく絵として直接見る。

図2: 1層目の重みを20x20に並べ直す

Section titled “図2: 1層目の重みを20x20に並べ直す”

1層目の重みは1ニューロンにつき 400 個で、入力画像と同じ次元数を持つ。 だから 400 個をそのまま 20x20 に並べ直せば、そのニューロンが画像のどこを見て 反応するかの地図になる。赤が正の重み(そこが黒いと反応が強まる)、 青が負の重み(そこが黒いと抑制される)。12個のニューロンぶんを並べる。

読み取り: どのニューロンにも、画像の中心付近に赤と青がまだらに散った 「テンプレート」らしき模様が浮かぶ。学習したのは構造(どこと繋がるか)ではなく この色の濃淡=実数値であり、しかもその値は平均絶対値 0.07 という 中途半端な小数である(直後の出力を参照)。0/1 では表現できないこの実数こそが、推論のたびに 掛け算を必要とする ── つまり乗算器が要る理由そのものである。

誤分類を見る

Section titled “誤分類を見る”

図3: 間違えた数字

Section titled “図3: 間違えた数字”

最後にモデルが外した10枚を並べる。「どう間違えるか」は精度の数字より モデルの素性を語る ── 人間でも迷う形で間違えているなら、モデルは形を捉えている。

読み取り(先に書いておく): 並ぶのは 4 と 9、7 と 1、3 と 5 のように 人間でも一瞬迷うペアばかりで、0 を 7 と読むような無関係な誤りは出ていない。 2000枚中およそ100枚を外す ── これが「実数の重みを持つ普通の MLP」の到達点であり、 次ページで論理ゲートに置き換えたときの比較基準になる。
