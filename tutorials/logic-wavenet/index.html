因果convolutionを論理ゲートで(WaveNet)

WaveNet のゲート付き活性 z=tanh⁡(⋅)⊙σ(⋅)z = \tanh(\cdot) \odot \sigma(\cdot)z=tanh(⋅)⊙σ(⋅) は、 {0,1}\{0,1\}{0,1} 上では ビット AND と同型になる。この事実を使って因果 convolution を 論理ゲートで組み、周期ビットパターンの次トークン予測で受容野の効き方を ablation する。

1層(受容野 RF=2)では直前1ビットからは決まらず 0.817 で頭打ち、3層(RF=8)で 1.000。 さらに位置 ppp の入力を反転して「変化した出力が [p,p+RF)[p, p+RF)[p,p+RF) だけである」ことを実測し、 因果性が回路レベルで保たれていることを確かめる。

このページで学ぶこと

  1. ゲート付き活性 tanh⁡⊙σ\tanh \odot \sigmatanh⊙σ が {0,1}\{0,1\}{0,1} 上でビット AND と同型になること
  2. 受容野(RF)を層数で伸ばす ablation の読み方(RF=2 で 0.817 → RF=8 で 1.000)
  3. 入力を1ビット反転して、因果性が回路レベルで保たれていることを実測する方法

LogicWaveNet: 「因果convolution」を論理ゲートで組む例。

09_logic_lstm.py の再帰(LSTM/GRU)は、時間方向にループを回して状態を運んだ。 系列を扱うもう一つの定番が dilated causal convolution —— WaveNet (van den Oord et al., 2016)の方式である。ループを持たず、 各位置が「自分と、指数的に離れた過去のタップ」だけを見る:

WaveNetの各層は ゲート付き活性 z = tanh(Wf·x) ⊙ σ(Wg·x) を使う。 LogicWaveNetの主張は、09と同じ筋の話である:

なので tanh も sigmoid も要らない。filter も gate も LutLayer で作り、 掛け算をそのままビットANDとして読める。eval(hard)時、z は厳密に {0,1} になる。

学習するのは「周期ビットパターンの次トークン予測」。周期5の 0,0,1,1,0 を 延々と繰り返す列を与え、各位置で次のビットを当てさせる。 直前1ビットだけでは決まらない(同じ 0 の次が 1 のときも 0 のときもある)ので、 受容野が足りているかどうか が正否を分ける —— そこを ablation で見せる。

アーキテクチャ図解 1: 受容野(dilation 1, 2, 4 の三角形)

Section titled “アーキテクチャ図解 1: 受容野(dilation 1, 2, 4 の三角形)”

3層構成(kernel_size=2)で位置 t の予測が どの入力まで遡って見ているか を、 そのまま木として描いたのが下の図。層を1つ上がるたびに手が届く距離が倍になり、 3層で 2³ = 8 ステップぶんの受容野になる。図に書いた 0/1 は実データ (0 0 1 1 0 の繰り返し)から切り出した8ビットで、正解の次ビットは 1 である。

木が 左にしか伸びない ことに注目。これが「因果(causal)」の意味で、 位置 t の出力は t より未来の入力に一度も触れない(左ゼロパディングで実装)。 1層だけ(RF=2)にすると木は x(t-1), x(t) の2枚しか掴めず、周期5のパターンでは (0,0) の次が 1 のときと 0 のときの両方が現れて決めきれない ── これが ablation の中身。

アーキテクチャ図解 2: 1層の中身(ゲート付き活性 = ビットAND)

Section titled “アーキテクチャ図解 2: 1層の中身(ゲート付き活性 = ビットAND)”

各層の中身は「連結 → filter と gate の2本 → AND → residual/skip」だけである。 本サンプルの構成では d_channels=32、conv_depth=1 なので、filter も gate も 64 ビット(=2タップ×32ch)→ 32 ゲート の LutLayer が1枚ずつ。

普通の WaveNet は tanh(...) ⊙ σ(...) という掛け算だが、{0,1} の上では 掛け算はビットANDそのもの。活性化関数を近似しているのではなく、一致している。

どう実現しているか(初めて読む人向けの要点)

  • 再帰を使わない。時間方向のループが無いので、全位置を一度に計算できる (09 の LSTM とはここが対照的)。
  • dilated = 飛ばし読み。層 l は d = 2^l ステップ前だけを見る。連続する 過去を全部見るのではなく指数的に飛ばすので、少ない層数で遠くまで届く。
  • 重みは全位置で共有。1枚の LutLayer を全時刻に使い回す(1次元 conv と同じ)。 つまり回路としては「1組のゲートを時間方向に並べる」だけで済む。
  • residual は XOR、skip は OR。実数NNの足し算に当たる部分も、ここでは 情報を潰さないブール演算に置き換えてある。
  • 端だけ実数: 埋め込みと最後の LM ヘッドは FP のまま(LogicGPT と同じ方針)。 中間の畳み込みは全て LUT。

実行: uv run python examples/10_logic_wavenet.py 期待結果: RF=8(3層)で hard accuracy 1.00 / RF=2(1層)は 0.8 で頭打ち(CPUで20秒程度)

準備: import とハイパーパラメータ

Section titled “準備: import とハイパーパラメータ”

使うのは LogicWaveNet と、その構成を決める LogicWaveNetConfig だけ。 再帰が無いモデルなので、時間方向のループを回すヘルパーも要らない。

ハイパーパラメータ

Section titled “ハイパーパラメータ”

学習データは周期5のビットパターンを繰り返しただけの系列。D_CHANNELS は各位置を 表すビット数(=論理チャネル幅)で、実数 NN のチャネル数にあたる。このページで 動かすのは層数だけで、他はすべて固定して比較する。

データ: 周期5のビット列で「次の1ビット」を当てる

Section titled “データ: 周期5のビット列で「次の1ビット」を当てる”

入力は 0 0 1 1 0 を繰り返した60ステップの系列で、正解はそれを1つ左へずらしたもの。 つまり各位置で「1つ先のビット」を当てる次トークン予測である。

なぜ周期5なのか: このパターンでは (0,0) の次が 1 のときと 0 のときの両方が 存在する。だから直前の1ビットだけでは原理的に決めきれず、どれだけ過去を見られるかが そのまま正解率になる ── 受容野の効き方を測るのにちょうどよい仕掛けである。

モデル定義: dilated causal convolution

Section titled “モデル定義: dilated causal convolution”

用語を3つ先に決めておく。

  • causal(因果) — 位置 ttt の出力が ttt より未来を見ないこと。次トークン予測では これが破れると答えを直接カンニングできてしまうので、設計上の絶対条件である
  • dilation(飛ばし読みの幅) — 層 lll は d=2ld = 2^ld=2l ステップ前だけを見る。連続する過去を 全部なめるのではなく指数的に飛ばすので、少ない層数で遠くまで届く
  • 受容野(RF, receptive field) — 出力1点が実際に見ている過去の長さ。2タップ・ dilation が 1,2,4,…1,2,4,\dots1,2,4,… と倍々なら、nnn 層で RF=2n\mathrm{RF} = 2^nRF=2n になる

ゲート付き活性がなぜ AND になるのか: WaveNet の tanh⁡(⋅)⊙σ(⋅)\tanh(\cdot) \odot \sigma(\cdot)tanh(⋅)⊙σ(⋅) は 掛け算だが、値が {0,1}\{0,1\}{0,1} に閉じているなら掛け算はビット AND そのものである。 活性化関数を近似しているのではなく一致している、というのがこのモデルの要点。 足し算にあたる residual も XOR、skip の集約も OR と、情報を潰さないブール演算にしてある。

学習ループ

Section titled “学習ループ”

再帰が無いので全位置を一度に計算でき、系列を (T,2)(T, 2)(T,2) に潰して普通の cross entropy を 取るだけで済む(バッチは1本だが、系列そのものが60個の訓練例を含んでいる)。 記録するのは hard(eval)側の精度のみ ── 焼いた回路が同じ答えを出すことだけを見る。

実行: 受容野を変えて比べる

データ

Section titled “データ”

入力と正解の先頭15ステップを並べて、「1つずれた同じ列」であることを目で確かめる。

受容野 ablation

Section titled “受容野 ablation”

ablation(切除実験) = 部品を1つだけ削って結果の変化を見る比較のこと。ここでは 層数だけを 1 と 3 に変え、受容野を RF=2 と RF=8 にして同じタスクを解かせる。 1層は「直前1ビットと自分」しか見えないので周期5のパターンは原理的に決めきれず、 3層なら周期をまたいで見えるので一意に決まる ── その予測が当たるかを確かめる。

上の出力で、RF=8 は 1.0000、RF=2 は 0.8 前後で止まっている。足りないのは表現力では なく、見えている範囲である ── 同じゲート種・同じ学習則で、窓の広さだけが結果を分けた。 下の2つの assert がこの対比を受入条件として固定している。

可視化: 受容野・因果性・ビット性

Section titled “可視化: 受容野・因果性・ビット性”

図1: 受容野が足りるかどうかで結果が分かれる

Section titled “図1: 受容野が足りるかどうかで結果が分かれる”

この図で何を見るか: 縦軸は hard accuracy、赤が1層(RF=2)、緑が3層(RF=8)。 点線が満点の位置である。見どころは「緑が 1.0 に届くか」ではなく、 赤がどれだけ学習しても 1.0 に届かないことのほうにある。

読み取り: 赤は 0.8 付近で平らになる。周期5のパターンのうち「直前1ビットでは 区別できない場面」の割合がちょうどそのくらいで、学習が足りないのではなく 情報が届いていないことによる天井である。緑は満点まで到達し、そこで止まる。 精度が伸びないときにまず疑うべきは学習率でも層幅でもなく受容野だ、という教訓の図。

図2: 因果性の実測(未来は本当に漏れていないか)

Section titled “図2: 因果性の実測(未来は本当に漏れていないか)”

この図で何を見るか: 位置 p=20p=20p=20 の入力だけを1ビット反転させ、どの位置の出力が 変わったかを棒で塗り分ける。期待される絵は「ppp より左は真っ白(未来が過去に 漏れていない)、ppp から RF ぶんだけ黒(影響が届く範囲)」である。

因果性はコードの構造で保証されている性質だが、設計の主張を実測で確かめるのが ここでの狙い。回路として焼いたあとも同じ検査がそのまま使える。

読み取り: 赤い縦線(ppp)より左に棒が1本も立たない ── 未来の情報が過去へ漏れて いないことの実測である。橙の破線(p+RFp + \mathrm{RF}p+RF)より右にも棒が無く、影響がちょうど 受容野の幅で止まっている。この2つを下の assert が機械的に固定している。

図3: ゲート付き活性 z = filter AND gate は本当にビットか

Section titled “図3: ゲート付き活性 z = filter AND gate は本当にビットか”

この図の見方と読み取り(このページ最後の図)。各層のゲート付き活性 zzz を 時間×チャネルの白黒画像にして、上から dilation の小さい順に積む。黒が1、白が0。

読み取りどころは2つ。(1) 灰色が1つも無いこと ── zzz が厳密に {0,1}\{0,1\}{0,1} である、 つまり「tanh⁡⊙σ\tanh \odot \sigmatanh⊙σ はビット AND と一致する」という主張の実測にあたる (直前の assert が同じことを機械的に確かめている)。(2) 下の層ほど模様が粗いこと ── dilation が倍々に広がるので、深い層ほど長い周期の構造を捉えている。
