パラメータ化を選ぶ

論理ゲートは本来「0 か 1 を返す早見表(LUT)」であって微分できない。 そこを 連続値のパラメータで包んで勾配を流す のがパラメータ化方式であり、 本ライブラリは 5 種類を実装している。ここでの選択が精度・パラメータ数・ 離散化後の回路の質をすべて左右する。

このページで分かること

  1. 5方式の違い — softmax / independent / iwp / raw / warp が何をパラメータに持ち、何を表現できるか
  2. 確定知見 — 「N=2 は softmax、N≥4 は independent(+学習率を上げる)」という結論と、その実験的根拠
  3. 選び方 — 目的(精度 / FPGA 面積 / 学習速度)からの決定フロー

softmax — エントリ(またはゲート)が競合する

Section titled “softmax — エントリ(またはゲート)が競合する”

重みの合計が 1 に固定される。「100円を箱に分配する」形なので、 1 つを上げると他が自動的に下がる。勾配が全パラメータへ連動して届くのが利点。

N=2 のときだけ特別扱いで、真理値表 4 エントリではなく 16 個の完全ブール関数の上で softmax を取る 16 ゲートモードになる(weights の形状が (out_dim, 16))。 argmax で選ばれるのは AND/OR/XOR/NAND… といった完成した関数そのものなので、 離散化しても表現力を失わない。

independent — エントリが独立

Section titled “independent — エントリが独立”

各エントリが独立に「1 になる確率」を持つ(σ(wk)\sigma(w_k)σ(wk​)、合計は 1 にならない)。 任意の真理値表をそのまま表現できるため、離散化しても表現力の欠落がない。 FPGA の LUT6 へ素直に対応する。

iwp — 入力ごとに 1 パラメータ

Section titled “iwp — 入力ごとに 1 パラメータ”

2N2^N2N ではなく NNN 個しか持たない。N=6 なら 64 → 6 でパラメータが 10 倍以上減り、 学習も速い。代償として XOR のような「組み合わせが本質」の関数を表現できない。 「学習済みモデルのゲートは大半が AND/OR/NOT に収束する」という観察に賭けた方式である。

raw / warp

Section titled “raw / warp”
  • raw — 重みを [0,1][0,1][0,1] の実数のまま持つ(初期化 N(0.5,0.01)\mathcal{N}(0.5, 0.01)N(0.5,0.01))。推論時も連続値を使い、ハードウェア展開の段階で初めて離散化する。
  • warp — 真理値表そのものではなく Walsh–Hadamard 基底の係数を学習し、ロジットの符号で離散化する。離散化ギャップがほぼゼロ(実測 MNIST N=2 で −0.06pp、つまり hard が soft を上回る)になり、softmax の 11〜48% の FLOPs で回る。高次係数を捨てる度数キャップ(wh_degree_cap)で回路をさらに絞れる。

確定知見: N=2 は softmax、N≥4 は independent

Section titled “確定知見: N=2 は softmax、N≥4 は independent”

まずこれだけ覚える

  • N=2 → softmax(16ゲートモード)
  • N=4 / N=6 → independent。加えて 学習率を上げる(0.01 → 0.1〜0.3 で切り分ける)

なぜ N≥4 で softmax を使ってはいけないのか

Section titled “なぜ N≥4 で softmax を使ってはいけないのか”

N≥4 の softmax は 16 ゲート表ではなく 2N2^N2N エントリ上の単体(simplex) になる。 合計が 1 なので、離散化(確率 > 0.5)で立てられるビットは高々 1 個 — つまり hard 表として作れるのは 単一 minterm か恒偽(FALSE)だけ である。 パススルー・OR・XOR といった日常的な関数が構造的に表現できない。

実験的根拠: 畳み込み構成で softmax(エントリ simplex)を independent に替えただけの 対照実験で、半分のエポック数にもかかわらず精度 +3.2pt を得た。 全結合の MNIST でも softmax N=4 は hard 94.54% / 離散化ギャップ 1.12pp にとどまり、 同条件の warp N=4(95.50% / 0.14pp)に劣る。 表現力の欠落は学習量では埋まらない、というのがこの知見の要点である。

なぜ学習率を上げる必要があるのか

Section titled “なぜ学習率を上げる必要があるのか”

independent は sigmoid 経由で、飽和気味の初期化(ロジット ±5 相当)と組み合わせると 深い直列合成で勾配が急速に減衰する。実測では全層の勾配ノルムが 10−510^{-5}10−5 程度まで落ち、 既定の lr=0.02 では 10 エポック回しても soft 精度が 1 桁目から動かなかった。 lr ≥ 0.3 で学習が進むことを確認しており、independent を使うときは まず学習率を 1 桁上げて切り分けるのが定石である。

読みどころ:

  • N=2 softmax が精度では頭一つ抜ける。ただしパラメータは 4 倍重い。
  • warp は離散化ギャップがほぼゼロ。soft の成績がそのまま回路の成績になる。
  • softmax N=4 だけギャップが大きい(1.12pp)。上で述べた表現力の欠落がそのまま数字に出ている。
  • 離散化後はどの方式も同一の LUT 回路になる。推論性能に差はなく、違いは訓練時だけである。

補足: 推定器 sin(論文 IWP)と、LUT 以外のゲート

Section titled “補足: 推定器 sin(論文 IWP)と、LUT 以外のゲート”

independent のエントリ確率 ωk=ρ(Ωk)\omega_k = \rho(\Omega_k)ωk​=ρ(Ωk​) の推定器 ρ\rhoρ は既定の sigmoid のほかに estimator: sin(ρ(Ω)=0.5+0.5sin⁡Ω\rho(\Omega) = 0.5 + 0.5\sin\Omegaρ(Ω)=0.5+0.5sinΩ。論文 Light Differentiable Logic Gate Networks の 実験設定)を選べる。残差初期化は Ω∼N(±μ,σ)\Omega \sim \mathcal N(\pm\mu, \sigma)Ω∼N(±μ,σ)(既定 μ=1.2\mu=1.2μ=1.2, σ=0.25\sigma=0.25σ=0.25)になる。 LutLayer と LutConv2d の両方で同じ指定が効く(LutConv2d(..., parameterization='independent', estimator='sin'))。

真理値表を直接持たないゲートとして LTTLayer(線形閾値ゲート) もある。ゲート j は yj=1[∑kwjkxjk+bj>0]y_j = 1[\sum_k w_{jk} x_{jk} + b_j > 0]yj​=1[∑k​wjk​xjk​+bj​>0] で、パラメータはゲートあたり N+1 個。表現できるのは 線形分離可能なブール関数(N=2 なら XOR / XNOR 以外の 14 種)に限られるが、学習は常に硬い値 + STE(ste='clip'|'identity'|'sigmoid')で離散化ギャップが構造的に無く、IR では他のゲートと同じ N 入力 LUT になる(export/discretize.py::truth_tables_from_ltt が全 2N2^N2N パターンを列挙する)。
