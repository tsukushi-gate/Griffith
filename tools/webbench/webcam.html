カメラの映像を1フレームずつ推論し、結果を重ねて表示します。 動かす手法は左のメニューの「手法」セレクタで1つだけ選びます (DLGN / ONNX Runtime Web / TensorFlow.js / MediaPipe)。 タスク・手法・計算方法は左のメニューで切り替えられます。 学習に使った写真とカメラ映像は写り方が違うため、精度は下がります。

MediaPipe はブラウザ向けの定番モデルです(顔検出は BlazeFace、 セグメンテーションは Selfie Segmenter)。いずれも大量の実データで学習した 実用モデルで、学習データの規模がこちらとは大きく違います。 とくにセグメンテーションは、MediaPipe が「人物と背景」、 こちらは「ペットと背景」を切り分けるモデルなので、切り分ける対象が違います。 公平に比べられるのは配信サイズ・読み込み時間・推論時間です。
