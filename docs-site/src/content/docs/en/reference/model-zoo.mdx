An **index that puts every model run in this library in one place**.
One line per model, with **a single sentence on what it solves**, **a single headline number** and
**a single line on the main open problem**; detailed conditions and discussion are delegated to the
linked pages. If you want the discussion, go to
[How far logic gates get, architecture by architecture](/en/explanation/results/architecture-survey/) and
[Models from the experimental branches](/en/explanation/results/experimental-models/).

**The "What it solves" column is compressed into one sentence that assumes no prior knowledge.**
The more concrete **input → output** and the **dataset** are collected in the collapsible block
directly under each table (keeping them out of the table is what keeps it readable on a phone).

:::caution[How to read the headline numbers]
- The values listed here are **full-run values**. The numbers that appear on the tutorial pages come
  from **scaled-down versions that finish in minutes on CPU** (fewer gates, fewer steps), so under
  different conditions they will not match. That is why the same model name can carry two numbers an
  order of magnitude apart.
- Unless noted otherwise, each row is a **single-seed, single-configuration** measurement; seed
  variance was not taken. Rows with multiple seeds say so inline.
- Metrics are reported primarily on the **hard** side (the pure Boolean circuit with gates fixed by
  argmax).
- Rows marked "needs calibration" are records that **have not converged and whose cause is not yet
  identified** — a current position, not an achievement.
- The single source of truth for the numbers is [Benchmarks](/en/reference/benchmarks/). If you find
  a contradiction, that page wins.
:::

## Badges for the strength of a world-first claim

The "World-first" column on this page does not express **the claim itself** but **how strongly the
audit backs it**.

> **S1** = paper-grade absence evidence (search queries, survey date and the scope of the claim all
> written out) / **S2** = falsification search audited (nearest literature cited, qualified form
> required) / **🟡** = close literature exists (survives only in qualified form) / **S3** = claim
> only, not audited / **Retracted** = withdrawn after a counterexample was found / **—** =
> reproduction or port (no world-first claim)

The basis for each verdict (search queries, survey dates, the wording of the qualified forms, and
the claims that were retracted) is in
[Auditing the "world-first" claims](/en/explanation/results/world-firsts/).
No badge proves that something "certainly does not exist"; each one means only that
**no counterexample was found within the scope of an exhaustive search**.
Preprints from the last few weeks, non-English literature and paywalled literature are outside that
scope.
