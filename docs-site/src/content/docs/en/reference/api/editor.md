Specification of a Python model exposed to the editor.

``build`` is set automatically from the function/class decorated with ``@editor_model``.
``input_spec`` / ``output_spec`` are expected to be dicts containing either ``width``
or ``shape``. When only ``shape`` is given, the product of its elements is used as the width.
