## DLGNBooleanAttention

Defined in: `griffith_logic.models.attention.boolean_attention.DLGNBooleanAttention` (class)

```python
class DLGNBooleanAttention(config: BooleanAttentionConfig, device: str = 'cpu')
```

Logic-gate version of the attention mechanism.

Architecture:
    input (batch, input_dim) binary vector in [0,1]
      ↓ parse_input
    Q (batch, key_bits), Ks (batch, num_pairs, key_bits), Vs (batch, num_pairs, value_bits)
      ↓ key_encoder / query_encoder / value_encoder (LutStack)
    q (batch, d_attn), k (batch, num_pairs, d_attn), v (batch, num_pairs, d_val)
      ↓ XNOR similarity
    scores (batch, num_pairs)
      ↓ value selection via softmax or argmax
    selected (batch, d_val)
      ↓ output_decoder (LutStack + GroupSum)
    logits (batch, num_classes)

Position-based DLGN attention.

Architecture:
    input: [V0, V1, ..., V(N-1), pos]  (flat binary)
      ↓ parse
    values (batch, num_slots, value_bits), pos (batch, pos_bits)
      ↓ key_encoder: fixed position indices [0..N-1] → (num_slots, d_attn)
      ↓ query_encoder(pos) → (batch, d_attn)
      ↓ value_encoder(values) → (batch, num_slots, d_val)
      ↓ XNOR similarity
    scores (batch, num_slots)
      ↓ softmax/argmax → selected (batch, d_val)
      ↓ output_decoder + GroupSum
    logits (batch, num_classes)

## DLGNAttentionSeq2Seq

```python
class DLGNAttentionSeq2Seq(config: AttentionSeq2SeqConfig, device: str = 'cpu')
```

A fixed-length seq2seq model built on DLGN Boolean Attention.

The query is based on the positional encoding of "output position t".
This lets attention learn "where the information I want at position t lives".
It corresponds to a simple Transformer with a single head and cross-attention only.

## DLGNPointerAttention

Defined in: `griffith_logic.models.attention.pointer_attention.DLGNPointerAttention` (class)

```python
class DLGNPointerAttention(config: PointerAttentionConfig, device: str = 'cpu')
```

A Pointer Network-style DLGN seq2seq model.

Architecture:
    Encoder (parallel):
      values (B, N, value_bits)
        → value_encoder → v_enc (B, N, d_val)    memory
        → key_encoder   → k_enc (B, N, d_attn)   content key

    Decoder (t = 0..N-1, recurrent):
      state_t = decoder_cell([state_{t-1}, prev_val])
      query_t = query_producer(state_t)
      scores_t = XNOR(query_t, k_enc) - mask_scale × used_mask
      attn_t = softmax(scores_t / τ) (training) / one_hot(argmax) (inference)
      selected_t = attn_t @ v_enc
      logits_t = group_sum(output_decoder(selected_t))

      teacher forcing: prev_val = v_enc[target_pointer[t]]
      free running:    prev_val = selected_t

      used_mask += attn_t

Bahdanau-style attention seq2seq.
