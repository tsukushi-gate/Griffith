## ThermometerEncoder

Defined in: `griffith_logic.encoding.thermometer.ThermometerEncoder` (class)

```python
class ThermometerEncoder(
    bits: int,
    mode: str = 'uniform',
    input_bits: int | None = None,
)
```

Thermometer encoding layer.


**Arguments**

- `bits` — number of bits z per feature (the number of thresholds)
- `mode` — 'uniform' (evenly spaced) | 'distributive' (empirical quantiles)
- `input_bits` — number of quantization bits B for the input when converting to IR (export_ir).
  With None (the default) the encoder stays at the boundary (outside the IR). When set, the extractor takes
  the per-feature B-bit code c (LSB first, position d·B + j) as input, treats it as the real value q = c / (2^B − 1)
  (the same as ToTensor's uint8 → [0, 1]), and bakes the threshold comparison into the truth table of a B-input
  lut_layer. The torch forward still receives the real value q as before


**Attributes**

- `thresholds` — (bits, n_features) thresholds (fixed after fitting)

## LearnableMapping

Defined in: `griffith_logic.layers.dwn.LearnableMapping` (class)

```python
class LearnableMapping(
    in_features: int,
    out_features: int,
    tau: float = _DEFAULT_LM_TAU,
)
```

Layer that learns the input→LUT connections by gradient descent.

During training it keeps a weight matrix W ∈ ℝ^{in×out}, and by default the forward
is the hard selection x_{argmax(W[:,i])} (no inference-time overhead).

Progressive wiring hardening (adapted from the two-phase scheme of SparseLUT arXiv 2503.12829):
    With forward_mode='soft' the forward becomes the soft mixture
    x @ softmax(W/tau_soft, dim=0) (pure autograd, no discontinuous jumps in selection).
    ProgressiveWiringScheduler decays tau_soft geometrically and switches to
    forward_mode='hard' (the usual argmax+STE) later in training.
    This is the lever introduced after wiring learning with hard selection collapsed in.
    Eval is always hard argmax (forward_mode is only consulted during training).


**Arguments**

- `in_features` — number of input bits P
- `out_features` — number of output bits Q (= number of LUTs × inputs per LUT)
- `tau` — softmax temperature for the backward pass (official default 0.001)
