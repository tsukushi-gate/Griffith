## LogicMLP

Defined in: `griffith_logic.layers.logic_linear.LogicMLP` (class)

```python
class LogicMLP(
    in_features: int,
    out_features: int | None = None,
    spec: LogicSpec | None = None,
)
```

A drop-in replacement for an entire Transformer FFN (Linear → activation → Linear).

A single LUT stack is more efficient than replacing the FFN with two LogicLinears,
so this is offered as its own class. When out_features is omitted it matches
in_features (a d_model→d_model FFN replacement).

Construction recipe for logic-gate layers.


**Attributes**

- `n_inputs` — number of LUT inputs (2/4/6)
- `parameterization` — LutLayer parameterization, plus 'dwn' (uses DWNLayer)
- `selection` — 'soft' | 'hard_st' (the CAGE approach; ignored for dwn)
- `depth` — number of LUT layers

- `neurons_per_output` — number of redundant neurons per output before GroupSum

- `encoder_bits` — bits per feature for the thermometer encoder
- `decoder` — output boundary: 'groupsum_centered' | 'groupsum' | 'layernorm' | 'identity'
- `decoder_tau` — decoder temperature (None → √group size)
- `connections` — 'random' | 'unique' (for dwn: learnable in the first layer, random afterwards)
- `grad_factor` — gradient scale for the LUT layers (>1 for deep configurations; ignored for dwn)

## ToLogic

Defined in: `griffith_logic.encoding.bridges.ToLogic` (class)

```python
class ToLogic(mode: str = 'sigmoid', tau_init: float = 1.0, bits: int = 8)
```

Real values → [0,1] conversion.

mode:
    'sigmoid'      — sigmoid(x/τ). τ is learnable (mitigates vanishing gradients from saturation)
    'binarize_ste' — binarize at threshold 0, backward is a HardTanh STE
    'identity'     — no conversion (when the input is already in [0,1])
    'thermometer'  — thermometer encoding (expands D → D×bits, STE).
                     Thresholds are fitted automatically on the first training batch (uniform)


**Notes**

thermometer changes the output width. Get the width for the next stage with out_width().


## FromLogic

Defined in: `griffith_logic.encoding.bridges.FromLogic` (class)

```python
class FromLogic(
    in_width: int,
    out_features: int,
    mode: str = 'groupsum_centered',
    tau: float | None = None,
)
```

[0,1] logic outputs → real values (group aggregation).

Splits the in_width logic outputs into out_features groups and sums each group,
then zero-centers and scales to recover a real-valued representation.

mode:
    'groupsum_centered' — (Σ - G/2)/τ. Keeps the mean well behaved even with residual connections (recommended)
    'groupsum'          — Σ/τ (same as the classic GroupSum, non-negative)
    'layernorm'         — groupsum_centered + LayerNorm
    'identity'          — no conversion (requires in_width == out_features)

τ defaults to √G (G = group size). Since the standard deviation of a sum of binary
outputs is √G/2, the output is normalized to O(1).

## replace_mlp_with_lut

```python
def replace_mlp_with_lut(
    model: nn.Module,
    spec: LogicSpec | None = None,
    mlp_class: type | None = None,
    mlp_name_pattern: str = '*mlp*',
    inplace: bool = False,
) -> tuple[nn.Module, list[str]]
```

Replaces whole FFN/MLP blocks with LogicMLP (the LL-ViT use case).

Attention, LayerNorm, and embeddings stay in PyTorch; only the MLP part becomes
LUT-based logic gates.

Detection criteria (either one):
    - if mlp_class is given: instances of that class
    - modules whose trailing name component matches mlp_name_pattern and that
      contain two or more nn.Linear inside

The in/out dimensions are inferred automatically from the first and last inner nn.Linear.
