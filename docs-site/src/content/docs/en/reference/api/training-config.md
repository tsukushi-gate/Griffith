## TrainConfig

Defined in: `griffith_logic.training.config.TrainConfig` (class)

```python
class TrainConfig()
```

Root of the training configuration (data/model/optim/run/expected_metrics).

expected_metrics: checks a recipe against its expected metrics.
Keys are '&lt;metric>_min' / '&lt;metric>_max' (metric being a key of run_training's
return value, e.g. hard_acc_min / final_loss_max). The runner prints the check
result on exit and stores it under the 'expected_metrics' key of the return value
(a miss does not raise; only `griffith train --strict` exits non-zero on a miss).
