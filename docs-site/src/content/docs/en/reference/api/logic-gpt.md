## LogicGPT

Defined in: `griffith_logic.models.logic_gpt.LogicGPT` (class)

```python
class LogicGPT(
    config: LogicGPTConfig,
    dfa_targets: list[str] | None = None,
    dfa_mode: str = 'micro',
    dfa_lr: float | None = None,
)
```

Logic-gate version of a decoder-only causal Transformer. forward(tokens[B,S]) → (logits, emb_reg).

Causality: logits[:, i] depends only on tokens[:, :i+1].
- LogicEmbedding / positional codes / head / GroupSum are all position-independent
- LogicTransformerBlock uses causal=True (never looks at future positions)
- LogicLayerNorm normalizes along the feature axis (d_model) and never crosses the sequence axis
