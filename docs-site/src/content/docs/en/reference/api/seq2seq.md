## RDDLGNClassifier

Defined in: `griffith_logic.models.rddlgn.RDDLGNClassifier` (class)

```python
class RDDLGNClassifier(
    config: RDDLGNConfig,
    n_classes: int,
    head_sizes: list[int] | None = None,
    device: str = 'cpu',
)
```

RDDLGN encoder + classification head (text-classification distillation such as SST-2, ROADMAP-v5 Track D7).

Structure: LogicEmbedding → RDDLGNEncoder (folds the sequence recurrently into a
context vector) → LutStack (classification head) → GroupSum(k=n_classes).
The difference from RDDLGN proper is that the seq2seq decoder (RDDLGNDecoder) is not
used — only the encoder's context output is.
