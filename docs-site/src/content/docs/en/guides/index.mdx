## Start here

The learning roadmap decides where to start across the whole site (it also carries the lookup table
from common architecture names — RNN/CNN/Transformer — to the tutorials here).
If you are unsure which architecture, parameterization, or learning rule to pick, the selection guide is the fastest route.
Coming from PyTorch, start from the mapping table and pick up only the differences.

## Deploy

There are two roads: running a trained model **as software** on devices you already have (the deploy kit), and burning it onto an FPGA **as a circuit**.
Both start from the same IR and are verified by integer-exact agreement with the same golden model.
