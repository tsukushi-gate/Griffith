このライブラリで動かしたモデルを**一箇所に並べた索引**である。
1モデル1行で「解くタスクを1文だけ」「代表精度を1指標だけ」「主要課題を1行だけ」に絞り、
詳しい条件・考察はリンク先に委譲する。考察を読みたい場合は
[アーキテクチャ横断の到達点](/explanation/results/architecture-survey/) と
[実験ブランチのモデル群](/explanation/results/experimental-models/) へ進んでほしい。

**「解くタスク」列は前提知識ゼロで読めるように1文へ圧縮してある。**
より具体的な**入力 → 出力**と**データセット**は、各表の直下の折りたたみにまとめた
(表を横に伸ばすとスマートフォンで読めなくなるため分けている)。

:::caution[代表精度の読み方]
- 掲載しているのは**本走値**である。各チュートリアルのページに出てくる数値は
  **CPU で数分の縮小版**(小さいゲート数・短いステップ)であり、条件が違うので一致しない。
  同じモデル名で桁の違う数値が2系統あるのはそのためである。
- 断りがない限り**単一シード・単一構成**の実測で、シード分散は取っていない。
  複数シードがあるものは行内に明記した。
- 指標はすべて **hard**(argmax でゲートを確定させた純ブール回路)側を主に載せる。
- 「要較正」と付いた行は**まだ収束していない・原因未特定**の記録であり、到達点ではなく現在地である。
- 数値の単一情報源は [ベンチマーク一覧](/reference/benchmarks/)。矛盾を見つけたらそちらを正とする。
:::

## 世界初主張の強度バッジ

このページの「世界初」列は、**主張そのもの**ではなく**主張を支える監査の強度**を表す。

> **S1**=論文級不在証明あり(検索クエリ・調査日・主張範囲の限定を明文化) / **S2**=反証探索監査済み(最近接文献明記・限定形必須) / **🟡**=近接文献あり(限定形でのみ生存) / **S3**=主張のみ・未監査 / **撤回**=反例発見により撤回済み / **—**=再現・移植(世界初主張なし)

判定の根拠(検索クエリ・調査日・限定形の文言・撤回した主張)は
[「世界初」主張の監査](/explanation/results/world-firsts/) にある。
いずれのバッジも「絶対に存在しない」ことの証明ではなく、
**網羅検索の範囲で反例が見つからなかった**という意味である。
直近数週のプレプリント・非英語文献・ペイウォール文献は網羅外。

- **LogicUNet** — 入力: 画像 `(B,C,H,W)` → 出力: 画素ごとのロジット `(B, out_channels, H, W)` / データセット: **mnist-mask**(MNIST 由来のマスク)と **pet64**。チュートリアルはノイズ入り MNIST 20×20 のマスク復元

</details>

<details>
<summary>入力 → 出力 と データセット(基盤・部品)</summary>

- **DWNClassifier** — 入力: 実数特徴 `(B, in_features)` を thermometer でビット化(MNIST 20×20 なら 400画素 × 3bit = 1,200bit) → 出力: クラスロジット / データセット: **MNIST**。ただし表の「配線4腕比較」は MNIST ではなく**トイ論理関数**(xor3・parity3n など)での比較である
