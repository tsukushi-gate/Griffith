「本当に論理ゲートだけで精度が出るのか」への一次的な回答が、**DLGN 論文
(Petersen et al., NeurIPS 2022) の MNIST 結果を、このライブラリの
`LutLayer` / `GroupSum` そのままで再現できるか**である。

結論から書く。**公式レシピに一致させると hard accuracy 0.9784**(全 10,000 枚の
テストセットで測定)で、論文の 97.69% を +0.15pt 上回った。ここで言う hard
accuracy とは、学習後に各ゲートを argmax で 1 つのブール関数に確定させ、
**純粋な論理回路として推論したときの精度**である。

:::note[このページの実験環境]
Modal 上の NVIDIA A10G(GPU 1 枚)、seed=0、2026-07-02 実施。
`LutLayer`(softmax パラメータ化・N=2)× 6 層 × 8,000 ニューロン + `GroupSum`。
数値は単一シードの実測値であり、シード分散は取っていない。
:::

## 1. 出発点: 素朴な再現は 4.4pt 足りなかった

再現テストの初期実装(4 層・τ=√(k/10)≈28.28・入力を 0.5 で二値化・random 接続・
テストセット先頭 2,000 枚で評価)では **hard acc 0.9285** にとどまり、
論文値との差は −4.4pt あった。この差が「実装の誤り」なのか「レシピの違い」なのかを、
1 要素ずつ戻すアブレーションで切り分けた。

## 2. 公式レシピに合わせた結果

| Run | 構成 | iteration | hard acc | soft acc | 実行時間 |
|---|---|---|---|---|---|
| A | 公式レシピ(mnist20x20・6層・τ=10・bs=100・unique 接続・連続値入力) | 50k | 0.9739 (best 0.9756) | 0.9751 | 2.7 分 |
| **A200** | **同上、論文と同じ 200k iteration** | **200k** | **0.9784 (best 0.9785)** | 0.9787 | 10.4 分 |
| C | 初期テスト構成(mnist784・4層・τ=28.28・bs=128・random・二値化入力) | 28k | 0.9489 (best 0.9497) | 0.9496 | 1.1 分 |
| C2 | C と同一モデルで「先頭 2,000 枚評価」を併記 | 28k | 0.9478 / **先頭2000では 0.9220** | 0.9489 | 1.1 分 |

C2 の行が決定的だった。**同じモデルでも、テストセット先頭 2,000 枚での評価は
フル 10,000 枚より約 2.6pt 低く出る**。先頭 2,000 枚が偶然難しい部分集合だった、
という測定バイアスである。

## 3. 要素別アブレーション

公式レシピ(50k iteration・hard 0.9739)から **1 要素だけ**初期テスト側に戻した結果。

| 変更点 | hard acc | Δ vs 公式 |
|---|---|---|
| (公式のまま) | 0.9739 | — |
| 訓練入力を 0.5 で二値化 | 0.9726 | −0.13pt |
| 6層 → 4層 | 0.9760 | +0.21pt |
| **τ=10 → 28.284** | 0.9639 | **−1.00pt** |
| mnist20x20 → mnist(784 入力) | 0.9745 | +0.06pt |
| unique 接続 → random 接続 | 0.9721 | −0.18pt |

## 4. 残差 −4.4pt の内訳

1. **測定バイアス 約 −2.6pt** — 先頭 2,000 枚評価がフル評価より一貫して低い。
2. **τ のスケール 約 −1.0pt** — τ=√(k/10)≈28.28 はロジットを過小スケールする。
   単独要因としては最大。公式は small 構成で τ=10 固定。
3. **複合レシピ差 + 訓練量 残り 約 −0.8pt** — 入力の二値化(−0.13pt)、random 接続
   (−0.18pt)、iteration 数(50k → 200k で +0.4pt)などの積み重ね。
4. **効かなかった要素** — 層数 4 対 6(50k では 4 層がわずかに上)、784 対 400 入力
   (ほぼ差なし)。ゲート予算が同じなら 28×28 のままでよい。

## 5. ここから読み取れること

- **実装差ではなくレシピ差だった。** 同じ `LutLayer` / `GroupSum` のまま、
  ハイパーパラメータを揃えるだけで論文水準に到達している。
- **τ(`GroupSum` の温度)は精度に効く。** 「なんとなく √(k/10)」で置くと 1pt 落ちる。
  設定の意味は [パラメータ化を選ぶ](/guides/parameterization/) と
  [学習を回す](/guides/training/) を参照。
- **評価に使うサンプル集合を必ず明示する。** 部分評価は 2〜3pt 単位で数字を動かす。
  本サイトに載る MNIST 系の数値は、断りがなければフル 10,000 枚での測定である。

再現手順そのものは [MNISTを学習する](/tutorials/mnist/) が最短経路になる。
横断的な数値一覧は [ベンチマーク一覧](/reference/benchmarks/) にまとめてある。
