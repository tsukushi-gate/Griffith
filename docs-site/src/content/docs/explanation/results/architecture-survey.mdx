---

MNIST が解けることは出発点にすぎない。ここでは **「論理ゲートだけでどこまでの
アーキテクチャが動くのか」** を、達成済みと未達に分けて実測で並べる。
数字を良く見せるための取捨選択はしていない。**較正が済んでいないもの・
崩壊したものも同じ表に載せる**。

実験ブランチのモデルまで含めた一行索引は [モデル動物園](/reference/model-zoo/) にある。

:::caution[数値の読み方]
断りがない限り、掲載値は**単一シード・単一構成の実測**であり、シード分散は取っていない。
指標はすべて **hard(離散化後の純ブール回路)** 側を主に記載する。
soft(学習時の連続緩和)の値は差分を見るためだけに併記する。
:::

## 1. 画像分類

| モデル | データセット | hard | 条件・環境 |
|---|---|---|---|
| DLGN(softmax N=2、6層×8,000) | MNIST 20×20 | **0.9784** | A10G、200k iter、2026-07-02 |
| DLGN(Hard-ST 選択、6層×64,000) | MNIST 28×28 | 0.9802 | RunPod GPU、50k iter、2026-04-15 |
| DLGN(softmax N=2、6層×16,000) | MNIST 28×28 | 0.9774 | RTX 5090、50ep、2026-04-20 |
| BinaryBrain 型(raw+BN+Binarize、N=6) | MNIST | 0.9483 | 14,516 ゲート、10ep、2026-04-20 |
| Conv-DLGN(`softmax16g` 修正後) | CIFAR-10 | 0.5808 | 修正前 0.4921(+8.9pt)、2026-07-05 |
| LogicMixer(MLP-Mixer 論理版) | MNIST | 0.671 で飽和 | 20k step、**要較正** |
| LogicResNet | MNIST | 0.113(ほぼ chance) | 3ep、loss は下降。**τ/スケール較正の問題として未解決** |

CIFAR-10 の値は MNIST 系より大きく落ちる。**タスク難度が上がるとゲート予算と
アーキテクチャの両方が効く**というのが現在地であり、ここは誇張せずに記録しておく。

Conv-DLGN の +8.9pt は、`LutConv2d` の構造欠陥(4 エントリ simplex では
パススルー / OR / XOR が表現できず、残差初期化も減衰していた)を `softmax16g` に
修正した結果である。**パラメータ化の表現力欠落がアーキテクチャ単位で精度を殺す**
実例で、詳細は [パラメータ化の選び方を決めた実験](/explanation/results/parameterization-study/) と対応する。

## 2. 言語モデル(自己回帰)

Tiny Shakespeare の文字レベル言語モデル(語彙 65・T=64・20k ステップ・A10G・seed=0)で、
Transformer をどこまで回路化できるかを段階的に測った「梯子」。

| 段 | 何を論理回路にしたか | hard ppl |
|---|---|---|
| L0 | 何も(全 FP。天井の確認) | 4.94 |
| L0b | FFN のみ論理 | ≈7.9 |
| L1 | + q/k/v 射影を回路化 | 19.24 |
| L2 | + スコアを XNOR-popcount 化 | 19.39 |
| L3-C | + 正規化を argmax MUX 選択器に(attention 完全回路化) | 15.54 |
| **L3-C + Gumbel** | 同上 + Gumbel ゲート選択ノイズ | **13.31** |

読みどころは 2 つある。

- **回路化のコストは単調ではない。** L1/L2 で 19 台まで落ちたものが、
  正規化を MUX に置き換えた L3-C で 15.5 に戻る。softmax による平坦化は
  必須ではなく、**attention は「学習されたマルチプレクサ」として成立する**。
  逐次 MNIST での対照実験でも、MUX 選択(entropy=0)は softmax(entropy=2.7)と
  同精度だった(0.8605 対 0.8606)。
- **FP 天井(4.94)との差はまだ大きい。** hard ppl 13.31 は「言語モデルが
  論理回路として動いた」ことは示すが、FP 実装に並んではいない。

離散化ギャップ側の詳細は [離散化ギャップの実態と対策](/explanation/results/discretization-gap/)。

## 3. 系列モデル(再帰・seq2seq)

| モデル | タスク | 結果 | 条件 |
|---|---|---|---|
| LogicLSTM | 遅延コピー(T=8) | **hard acc 100%(全 seed、≤200 step)** | 同条件の Elman 型は 800 step でも ≈0.86 |
| LogicReservoir(凍結ランダム回路) | 遅延ビット再生 | **readout の学習だけで hard acc 100%(全 seed)** | 回路本体は凍結・純ブール状態 |
| DLGNAttentionTranslator | copy(seq_len=16) | soft 71.66% / hard 25.77% | 50,000 step、156,032 パラメータ / 9,352 ゲート |
| RDDLGN(先行手法の再実装) | copy(seq_len=16) | soft 22.54% / hard 15.54% | 同条件、180,608 パラメータ / 10,888 ゲート |

**Cross-Attention を入れた Translator が、13.6% 少ないパラメータで RDDLGN の
soft 精度 3.18 倍・hard 精度 1.66 倍**を達成した(2026-04-21)。
RDDLGN の attention 無し構造による情報ボトルネックが実際に効いていた証拠になる。
ただし hard 25.77% は実用水準ではなく、**seq2seq は現時点で最も離散化に弱い領域**である。

ゲーティングについては、`LogicLSTM` の eval 時にゲートが `{0,1}` に離散化されて
厳密なブール MUX 回路に崩壊することをテストで担保している。
**ゲーティング = MUX / AND マスクは本来ブール演算と親和的**というのが実測の示す姿である。

## 4. 検出・密予測

| モデル | タスク | hard | 環境 |
|---|---|---|---|
| CenterNetLUT | Multi-MNIST 検出(96×96、1 物体) | **mAP 0.5425**(epoch 78、**修正前指標・再計測待ち**) | RTX 5090、1,000ep、11h45m、13,944 パラメータ |
| LogicUNet | 8×8 トイ領域分割 | IoU 0.875 | **要較正** |
| LogicUNet | フル MNIST マスク | IoU 0.373 | **要較正** |

CenterNetLUT は epoch 78 でピークに達したあと不安定化する。
hard が soft(mAP 0.1791)を大きく上回るという珍しい挙動で、
**hard 側を基準にモデル選定しないとピークを取り逃す**。

## 5. 生成モデル

| モデル | タスク | 結果 | 条件 |
|---|---|---|---|
| LogicBinaryDiffusion(前向き・逆過程・デノイザすべてブール回路) | binary MNIST | acc@t1 0.886、デノイズマージン +0.377(passthrough 基準 0.499) | 4ep、総パラメータ **3,937** |
| LogicVAE(二値潜在・ST Bernoulli) | binary MNIST | 再構成 193.6 nat/枚、KL 0.448、active_bits 0.99(posterior collapse なし) | 30ep |
| LutAutoencoder(LutLayer のみ) | MNIST 再構成 | Test MSE(hard) **0.0863**(epoch 63 のベスト) / 同 epoch 65 の soft 0.0438 | Apple M4 Pro(MPS)、k=8,000・bottleneck=256、65ep(途中停止)、30,784 ゲート |
| LogicGAN | 8×8 二値パターン | 未調整では発散。安定化策で拮抗まで | **研究課題**(構造契約とダイナミクスのスモークのみ) |

拡散モデルの **3,937 パラメータ**という数字は注目に値する。
「サンプリング = 比較器」「ノイズ付加 = XOR」という対応があるため、
生成過程が論理回路のまま閉じられる。

## 6. テキスト分類(実データ)

WRIME(日本語 SNS 投稿の感情分析)での LUT ベース TextCNN。いずれも hard 側の値である。

| タスク | 結果 | 比較対象 |
|---|---|---|
| 2 値分類 | Accuracy **82%** | — |
| 8 感情 2 値分類 | Accuracy **83.4%** / 平均 F1 **0.367** | DeBERTa-v3-base 87.0% / F1 0.630 |

8 感情版はパラメータ約 208 万(DeBERTa の 1/88)で、Accuracy −3.6pt・F1 −0.263。
**Accuracy は肉薄するが F1 は大きく劣る**。少数クラスを取りこぼしており、
「精度が近い = 同等」ではないことを明示しておく。訓練時間は GPU で約 15 分だった。

## 7. 事前学習モデルからの変換

既存の浮動小数点モデルを論理ゲートに変換できるか(Track D)。

| 経路 | 結果 |
|---|---|
| 枝刈り転写 + STE fine-tune + int4 QAT + 加算木 lowering(MNIST) | **teacher −2% 以内を達成(hard 0.9558、厳密 lowering)**。回路は 418k LUT 出力 |
| 同レシピの Fashion-MNIST 転移 | 0.8196(fan-in 48 + bits 6 で通過) |
| 強 teacher(公開 ResNet18 CIFAR-10、0.9498)からの KD | dense DLGN で scratch 比 **+2.3pt** |
| 弱 teacher(MNIST)からの native DLGN 変換 | 3 経路すべて **scratch 未満**(負の結果) |
| 公開 DistilBERT → SST-2 感情分類の KD | hard 精度 **+7.3pt**(73.4% → 80.7%、回復率 88.4%) |
| 公開 nanoGPT → 文字 LM のデータフリー蒸留 | RDDLGN 実 BPC **2.71**(教師との差 0.51 bit) |

ここでの中心的な知見は **「teacher と student の実力差が蒸留の利得の源泉」** という
スケーリング仮説である。弱い teacher からの変換は scratch 学習に負ける。
逆に、学習データ無し(教師生成テキストのみ)でも言語生成の変換が成立した点は、
実運用で元データが手に入らない場合の道筋になる。

## 9. 現在地のまとめ

- **確実に動く**: 画像分類(MNIST 級)、遅延コピー等の再帰タスク、検出の単純設定、
  二値潜在の生成モデル、テキスト分類。
- **動くが FP に届かない**: 自己回帰言語モデル(hard ppl 13.31 対 FP 天井 4.94)、
  CIFAR-10 級の画像分類(0.5808)。
- **未達 / 較正中**: LogicResNet(≈chance)、LogicMixer(0.671 で飽和)、
  LogicUNet(フル MNIST で IoU 0.373)、LogicGAN(安定化が研究課題)。
- **共通のボトルネックは離散化ギャップ**であり、対策の現状は
  [離散化ギャップの実態と対策](/explanation/results/discretization-gap/) にまとめてある。
