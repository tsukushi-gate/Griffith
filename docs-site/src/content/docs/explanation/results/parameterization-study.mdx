`LutLayer` は 5 種類のパラメータ化(`softmax` / `independent` / `iwp` / `raw` / `warp`)を
持つ。どれを選ぶかで精度・パラメータ数・離散化後の回路の質がすべて変わる。
ここでは **運用ルール「N=2 は softmax、N≥4 は independent」がどの実測から出たのか**を
たどる。方式そのものの説明は [パラメータ化を選ぶ](/guides/parameterization/) にある。

## 1. 同条件比較 — softmax と warp、N=2 と N=4

:::note[実験環境]
NVIDIA GeForce RTX 5090 (32GB)、MNIST 28×28、6層、τ=10、50 エポック、
bs=128、lr=0.01、seed=0。2026-04-20 実施(単一シード)。
:::

| | softmax N=2 | warp N=2 | warp N=4 | softmax N=4 |
|---|---|---|---|---|
| **hard 精度** | **97.74%** | 96.11% | 95.50% | 94.54% |
| soft 精度 | 98.30% | 96.05% | 95.64% | 95.66% |
| 離散化ギャップ | 0.56pp | **−0.06pp** | **0.14pp** | 1.12pp |
| ゲート数 | 96,000 | 96,000 | **24,000** | **24,000** |
| パラメータ数 | 1,536,000 | **384,000** | **384,000** | **384,000** |
| 訓練時間 | 5.0 min | 3.1 min | **2.1 min** | 1.7 min |
| 訓練時 FLOPs/サンプル | 16,896,000 | 1,920,000 | **1,440,000** | 2,976,000 |

読みどころは 4 つある。

- **精度は softmax N=2 が頭一つ抜ける**(97.74%)。ただしパラメータは 4 倍重い
  (N=2 の 16 ゲートモードは 1 ゲート 16 パラメータ)。
- **warp は離散化ギャップがほぼゼロ**。N=2 では −0.06pp、つまり hard が soft を
  わずかに上回った。soft の成績がそのまま回路の成績になる。
- **softmax N=4 だけギャップが 1.12pp と大きい**。これは表現力の欠落が数字に出たもので、
  下の §2 が理由を説明する。
- **訓練時 FLOPs は warp が softmax の 11〜48%**。softmax の exp 演算(48 FLOPs)と
  16 ゲート表の乗算(112 FLOPs)が不要になるため。

### 効率で見るとランキングが入れ替わる

| 指標 | softmax N=2 | warp N=2 | warp N=4 | softmax N=4 |
|---|---|---|---|---|
| 精度 / K ゲート | 0.0102 | 0.0100 | **0.0398** | 0.0394 |
| 精度 / M パラメータ | 0.636 | **2.503** | 2.487 | 2.462 |
| 精度 / 訓練分 | 0.198 | 0.305 | 0.451 | **0.556** |

**ゲートあたりの精度では N=4 が約 4 倍効率的**である。1 ゲートの表現力が高いぶん、
同じ精度域を 1/4 のゲート数で到達できる。FPGA 面積が制約になる用途では、
最高精度ではなくこの列を見るべきである。

離散化後の回路はパラメータ化によらず同一の LUT 回路になる。
**推論時の性能差はゼロで、違いは訓練時だけ**という点も重要である。

## 2. N≥4 で softmax を選んではいけない理由

N≥4 の softmax は 16 ゲート表ではなく $2^N$ エントリ上の単体(simplex)になる。
合計が 1 に固定されるので、離散化(確率 > 0.5)で立てられるビットは高々 1 個 —
**hard 表として作れるのは単一 minterm か恒偽(FALSE)だけ**になる。
パススルー・OR・XOR といった日常的な関数が構造的に表現できない。

対して `independent` はエントリごとに独立な sigmoid を持つため、任意の真理値表を
そのまま表現できる。畳み込み構成で `softmax`(エントリ simplex)を `independent` に
差し替えただけの対照実験では、**半分のエポック数にもかかわらず精度 +3.2pt** を得た。
全結合 MNIST 側の数字(softmax N=4 が hard 94.54% / ギャップ 1.12pp で、
同条件の warp N=4 の 95.50% / 0.14pp に劣る)とも整合する。

**表現力の欠落は学習量では埋まらない**、というのがこの知見の要点である。

## 3. `independent` を使うときは学習率を上げる

`independent` は sigmoid 経由なので、飽和気味の初期化と深い直列合成が重なると
勾配が急速に減衰する。実測では全層の勾配ノルムが $10^{-5}$ 程度まで落ち、
既定の lr=0.02 では 10 エポック回しても soft 精度が動かなかった。
**lr ≥ 0.3 で学習が進む**ことを確認している。

```bash
# N=6(FPGA LUT6 互換) + independent + 学習率を上げる
uv run griffith train configs/recipes/dlgn_mnist_quick.yaml \
    model.n_inputs=6 model.k=4000 model.parameterization=independent optim.lr=0.3
```

## 4. `raw` 系(BinaryBrain 流)との比較

`raw` パラメータ化に BatchNorm と Binarize を挟む BinaryBrain 型の構成は、
**ゲート数を揃えた比較で少ゲート域が強い**。2026-04-20、MNIST・N=6・10 エポックでの実測:

| ゲート数の水準 | BinaryBrain(raw+BN+Binarize、バイナリ変調 15 フレーム) | DLGN(softmax・均一幅) |
|---|---|---|
| 約 3,200 ゲート | **93.08%**(3,182 ゲート / 210,012 パラメータ) | 63.52%(3,180 ゲート / 203,520 パラメータ) |
| 約 16,000 ゲート | **94.83%**(14,516 ゲート / 958,056 パラメータ) | 93.38%(16,000 ゲート / 1,024,000 パラメータ) |
| FLOPs/サンプル(3.2K ゲート時) | 43.11 MFLOPS | **2.85 MFLOPS** |
| 壁時間(3.2K ゲート時) | 1 分 44 秒 | **11 秒** |

差の主因は分解できている。BinaryBrain は 1 サンプルを 15 通りの閾値で二値化して
推論を平均する**バイナリ変調**を使っており、これがアンサンブル効果を生む代わりに
FLOPs を 15 倍にする(実測比 43.1M / 2.85M = 15.1 倍で、ちょうど変調フレーム数に一致)。
さらに各層の BatchNorm + Binarize が中間表現を `{0,1}` に戻すため、LUT の入力品質が高い。

一方で BinaryBrain 側は 2〜3 エポックでピークに達したあと劣化する傾向があり
(10 エポックで 94.83% → 92.99%)、原因は BatchNorm の `momentum=1.0`(running stats を
毎バッチ完全置換)にあると特定している。DLGN 側は単調改善で安定していた。

**使い分け**: FPGA リソースが厳しい → BinaryBrain 型、学習・推論速度重視 → DLGN 型、
ゲート数を十分確保できる → DLGN 型のほうが単純で安定、となる。

## 5. まとめ

| 目的 | 選ぶもの | 根拠 |
|---|---|---|
| 最高精度 | `softmax` N=2 | MNIST hard 97.74% |
| FPGA 面積最小 | `warp` N=4 | 24K ゲートで 95.50%、リソース 1/4 |
| 離散化ギャップ最小 | `warp` | −0.06pp 〜 0.14pp |
| N≥4 で hard 精度 | `independent`(+ lr 0.1〜0.3) | softmax N≥4 は単一 minterm しか作れない |
| 少ゲートでの精度 | `raw` + BN + Binarize(BinaryBrain 型) | 3.2K ゲートで 93.08% |
