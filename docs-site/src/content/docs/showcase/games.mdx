ゲームや古典的な制御課題では、論理回路とNN(実数の重みを持つ従来のNEAT)の得意・不得意がはっきり分かれた。
**「通るか、通らないか」を判断する課題では論理回路が強く、推力を細かく調整する課題ではNNが強い。**

## Flappy Bird: 11ゲートの圧勝

<ShowcaseVideo
	name="flappy_dlgn.mp4"
	caption="論理回路(11ゲート)のFlappy Bird。"
	meta="2本とも攻略(適応度48.64 / 54.63)"
/>

観測は「次のパイプの位置」「すき間の中心との高低差」「自分の高さ」「自分の上下の速さ」の4つの値だけで、回路には32ビットとして入る。
**論理回路は11ゲートで2本とも攻略した**。NNは論理回路の3.5倍にあたる900世代をかけても、適応度は約11にとどまった。
パイプのすき間に入るかどうかという離散的な判断は、論理ゲートの得意分野だ。

さらに、攻略したときの行動を1ステップも変えずに回路を削ると、11ゲートは4ゲート・2ゲートまで縮んだ。

## 2Dレースカー: 1周できたのは論理回路だけ

<ShowcaseVideo
	name="car2d_dlgn.mp4"
	caption="論理回路(23ゲート)の周回。"
/>

7本の距離センサーと速度を64ビットに変換して回路に入れ、「前進・左・右・ブレーキ」のどれかを選ぶ。
**論理回路は22〜23ゲートで2本ともコースを1周した**。NN(66〜91パラメータ)は2本とも1周できなかった。

## スネーク

<ShowcaseVideo
	name="snake_dlgn.mp4"
	caption="論理回路(14ゲート)のスネーク。"
/>

観測はもともと11ビットの0/1なので、そのまま回路に入る。
論理回路は12〜14ゲートで2本とも餌10個の目標を達成し、NNは2本中1本だった。
ただし一番多く餌を集めたのはNNの当たりの1本(23.37に対し論理回路の最良は17.14)で、強さでは負けている。

## ロボットアーム

### 2関節アームで物を運ぶ

<ShowcaseVideo
	name="arm2d_dlgn.mp4"
	caption="論理回路(29ゲート)のアーム。近づく・掴む・運ぶ・離す、を順に行う。"
/>

物に近づき、掴み、目標まで運んで離す、という段階を順に踏む課題。
両方式とも目標の得点には届かなかったが、29ゲートの回路は2000回中33回(1.65%)物を運び切った。
ランダムに動かすと2000回中0回なので偶然ではないが、「運べることがある」以上のことは言えない。

### Reacher(腕の先を目標へ)

<ShowcaseVideo
	name="reacher_dlgn.mp4"
	caption="論理回路(36ゲート)のReacher。"
/>

MuJoCoのReacher。2つの関節を「正・ゼロ・負」の3択で動かす。
論理回路は36ゲート、NNは32パラメータで、どちらも最初の世代よりは良くなったが、伸びは小さく、部分的な成功にとどまった。
