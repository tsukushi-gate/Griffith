「世界初」主張の監査

このプロジェクトは「論理ゲートで◯◯を実現したのは世界初」という主張を複数持っている。 本ページは、それらを擁護するためではなく反証を探した結果の記録である。 判定・最近接文献・限定形の文言・撤回した主張まで、そのまま公開する。

主張の強度を横並びで比較できることが目的なので、判定の根拠(検索クエリ・調査日・ 限定の生命線)を主張ごとに明示し、根拠が薄い主張は薄いと分かる形で並べている。

1. 監査の手法

Section titled “1. 監査の手法”

1.1 反証探索(裏付けではなく反例を探す)

Section titled “1.1 反証探索(裏付けではなく反例を探す)”

主張の裏付けを集めると、確証バイアスによって「見つからなかった」が 「存在しない」にすり替わる。そこで各主張について、その主張を殺す論文を探す 姿勢で検索を実行している。

  • 主張ごとに 4〜10 本のクエリを実行する(汎用Web検索 + arXiv API の全文/abstract検索 + 個別 abs ページの精読)
  • ヒットしなかったこと自体を陰性所見として記録する (例: arXiv API abs:"logic gate" AND abs:"text classification" は 総ヒット0件、 abs:"logic gate network" AND abs:"distillation" も 総ヒット0件)
  • 関連論文の Related Work を辿り、隠れた直接競合がいないかを二次的に確認する
  • 使用クエリの全リストと調査日を、主張ごとに残す(後から第三者が同じ検索を再実行できる形にする)

1.2 3値判定

Section titled “1.2 3値判定”
判定意味
生存(反例なし)網羅検索の範囲で反例が見つからなかった
条件付き生存(近接あり)限定語を維持すれば生存する。限定を1つでも外すと死亡する
死亡(反例あり)反例が存在する。主張を撤回または縮小する

「条件付き生存」では、どの限定語が生命線かを必ず書く。 たとえば FPGA 上での自己回帰生成の主張は「FPGA実機 × テキスト生成 × 非命令セット型」の 三重限定が生命線で、どれか1つを外すと既存研究に直撃される。

1.3 鮮度の再確認

Section titled “1.3 鮮度の再確認”

この分野は進行が速く、2025〜2026年に空白が次々と埋まった実績がある。 そのため過去の判定を固定せず、定期的に再監査して格下げする運用にしている。 直近の再確認(2026-09-05)では、2ヶ月間で死亡した主張は0件だったが、 1件が ✅ → 🟡 に格下げされ、1件が対比記述の改訂を要すると判定された。

1.4 この監査の限界(先に書いておく)

Section titled “1.4 この監査の限界(先に書いておく)”
  • 直近数週のプレプリントは網羅外。査読中・未公開の並行研究は捕捉できない
  • 非英語文献は網羅外(日本語は一部のみ実施。中国語・ポルトガル語などは未調査)
  • 非 arXiv・ペイウォール文献の全文検索は間接的。とくに FPGA 系ワークショップ (FPL / FCCM / ASAP / ICFPT)と組込系ジャーナルは arXiv 化率が低く、埋もれている可能性がある
  • 特許文献の体系的調査は未実施。RAM型NN分類器の特許は実在するため、 出願を検討する場合は別途の専門調査が必要
  • abstract 止まりの判定が一部ある。本文精読で限定形をさらに狭める必要が出る場合がある

2. 強度バッジの定義

Section titled “2. 強度バッジの定義”

主張の「証拠の強さ」を、判定そのものとは別の軸として明示する。

バッジ意味
S1論文級不在証明あり(検索クエリ・調査日・主張範囲の限定を明文化)
S2反証探索監査済み(最近接文献明記・限定形必須)
🟡近接文献あり(限定形でのみ生存)
S3主張のみ・未監査
撤回反例発見により撤回済み
—再現・移植(世界初主張なし)

S3 と — はこの表には現れない。S3 は監査を通していない主張に付くバッジで、 本ページに載せる前に監査へ回す運用にしている。— は DLGN 再現や既存手法の 移植のように、そもそも世界初を主張していない成果物に付く。

4. 撤回の記録 — A4「論理リザバー」

Section titled “4. 撤回の記録 — A4「論理リザバー」”

この節を残すことが、他の判定を信じてよい根拠になる。 撤回した主張を消して回るなら、生存している主張も同じように扱われている可能性がある。

  • もとの主張: 凍結したランダム論理回路をリザバーとし、読み出し層のみを学習する構成は世界初
  • 判定: 死亡(反例あり)。2026-07-10 の再調査で発見
  • 反例:
    • LUTNet-RC(IEEE ICFPT 2023) — LUT ベースのリザバーコンピューティング
    • Random Boolean Network(RBN)リザバー — 2000年代からの古典研究(Snyder ら ~2013 ほか、20年来の蓄積)
    • CMOS ゲートによるリザバー(ACM 2021)
  • なぜ見落としたか: 「微分可能論理ゲートNN」という自分たちの語彙で検索していたため、 RBN / reservoir computing 側の語彙(周辺分野の別系統)に到達していなかった。 反証探索を「隣接分野の語彙でも検索する」形に広げたのは、この失敗が契機である
  • 修正後の主張: 「凍結ランダム論理回路+学習 readout」の中核は先行研究に帰属する。 当方の貢献は 微分可能フレームワークへの統合・同一 IR からの HDL 出力・ 他部品(GPT/LSTM)との学習則の共有に限定する。論文化する際は LUTNet-RC と RBN リザバーを必ず引用する
  • 波及: モデルの docstring・ロードマップ・報告書に残っていた「世界初」表現を撤回・書き換えた。 同種の言い過ぎ(WaveNet・検出・テキスト分類)も、その後の監査で順次限定形へ直している

5. 4象限マップ

Section titled “5. 4象限マップ”

横軸 = 新規性の強度(左: 限定形でのみ生存 → 右: 強い不在証拠)、 縦軸 = 実測の到達度(下: 較正中・本走未 → 上: 実測で確定)。

象限ごとの意味と所属を、テキストでも示す。

実測で確定している(上)較正中・本走未(下)
新規性が強い(右)主力。LogicGPT(A1/A2)・完全論理拡散(B1)・LogicVAE(B2)・LogicLSTM(A3)・SST-2 KD(W3)。論文化の第一候補はここから選ぶ空白地帯だが未実証。LogicMixer(B4a)・LogicGAN(B3)・LogicResNet(B4b)。新規性で語らず、まず数値を出すべき領域
限定形でのみ生存(左)実績で戦う。TextCNN(W1)・8感情(W2)・CenterNet-LUT(B4d/W5)・Attention Seq2Seq(W4)・フレームワーク幅(B5)。「初」ではなく到達した数値と差分を前面に出す要再定義。LogicUNet(B4c)・LogicWaveNet(B4e)・LogicReservoir(A4、撤回済み)。限定形を狭めるか、主張を降ろす

読み方の要点は 2 つある。

  • 右上が薄いことが現状の正直な姿である。新規性が強い主張ほど実測が浅い傾向があり、 逆に実測が固いテキスト分類・検出は先行研究が近い
  • 左下は「主張を降ろす」判断の対象。撤回した A4 がここに残っているのは、 撤回後も実装と実測(凍結性・fading memory・readout 学習のみでの収束)自体は 価値として残るためで、新規性の主張だけを取り下げている

6. 「世界初」は絶対不在の証明ではない

Section titled “6. 「世界初」は絶対不在の証明ではない”

本ページのすべての判定は、次の意味に限られる。

調査日時点で、記載の限定形において、記載のクエリによる網羅検索では反例を発見できなかった。

これは「存在しないことの証明」ではない。上の §1.4 のとおり、直近数週のプレプリント・ 非英語文献・ペイウォール文献・特許・未論文化の実装は網羅外である。

したがって、対外資料・論文・発表で本プロジェクトの新規性に触れる場合は、 次の 3 点を守ることを運用ルールとしている。

  1. 限定形で書く。判定表の「限定形の文言」をそのまま使い、限定語を落とさない (限定語を1つ外すだけで死亡する主張が複数ある)
  2. 最近接文献を必ず併記する。差分を示さずに「初」だけを書かない
  3. 調査日を添える。判定には賞味期限がある。分野の進行は速く、 2ヶ月の再確認で 1 件が格下げされている

新しい主張を立てるときは、まず反証を探す。見つかったら、隠さずにこのページへ書く。
