実験ブランチのモデル群

パッケージ本体に入っているモデル(= モデル動物園 の前半)とは別に、 実験ブランチ上でだけ走らせた構成が多数ある。ここはその置き場である。 本流のページと違い、負の結果とその理由を主役として書く。 「効かなかった」で終わらせず、なぜ効かなかったかを毎回残すのがこのページの目的である。

収録は 11系統・81構成(実験系列ID で数えると 24 系列)。 すべて experiments/ 配下のスクリプトで実行し、指標は wandb に記録してある。

全系統に共通する読み方の注意

  • seed 1本が大半。seed 3本を取ったのは LUT6-1(1層条件)・HYBRID-4b・RES-LN-2(rezero-n2)・ VAE-1(logic-n6 / float-bern-match)のみ。上位帯 0.980〜0.984 の 0.3pt 以内の順位は主張できない。
  • 等ゲート予算 ≠ 等パラメータ。N=2 softmax は 16 パラメータ/ゲート、N=6 は 64、 AP 法の independent は 4。表をまたぐときは必ず確認すること。
  • エポック非等の暫定値が混ざる: 後段スケールの 16M(10ep)・61M(5ep 途中打切)、 Logic-DenseNet の CIFAR dense/plain(61ep 打切)。
  • FPGA の数値はすべて理論値(200MHz・1層1クロックの完全パイプライン、未配置配線の上限)。 Vivado 合成による実測は未実施。
  • ハイブリッド系は文献と土俵が違う。前段に浮動小数 NN(約20万〜165万パラメータ)を含み、 ハードウェア化できるのは二値界面から後ろだけである。ネットワーク全体が論理ゲートである 文献(difflogic / DWN / LogicTreeNet / LILogicNet)とゲート数だけを横並びにした比較は成立しない。 同条件で言えるのは「同じ前段・同じ界面での後段の寄与」と「純 DLGN との相対」までである。

1. 純DLGN / 入力バイパス — 固定配線の工夫は一度も勝てなかった

Section titled “1. 純DLGN / 入力バイパス — 固定配線の工夫は一度も勝てなかった”

何を試したか: 純 DLGN(入力 400bit → LutLayer×L → GroupSum、学習するのはゲート種別のみ)の 弱点は入力層のランダム疎結合にあるという仮説を立て、生入力を各層へ配り直す配線の工夫を 5 ラウンド(R1〜R5)・約30 run 試した。条件は mnist20x20(400bit)・n_inputs=2・τ=10・bs=128・ seed 0・配線 fixed で固定。

2. ハイブリッド — 前段NN/CNN + 二値界面 + 後段DLGN

Section titled “2. ハイブリッド — 前段NN/CNN + 二値界面 + 後段DLGN”

何を試したか: 前段 NN(Linear+ReLU または Conv)→ Sigmoid → Binarize(0.5, STE) の ビット界面を立て、その先を完全に論理ゲート(LutLayer 列 → GroupSum)にする。 界面から後ろはそのまま HDL に落ちる。前段MLP(HYBRID-1)、前段CNN(HYBRID-2)、 後段の形状探索(HYBRID-3)、配線と LUT6 の決着(HYBRID-4/4b)、GPU/FPGA 境界の掃引(HYBRID-5/6) の6段構成。

構造図(系列最良の h2-cnn-dlgn-expand = CIFAR-10 hard 0.7864 の実寸)

読み方: 界面より右(緑)だけが 1,120 個の2入力 LUT で、Verilog に落ちる。 左(橙)は普通の CNN なので GPU が要る。 全 NN 対照(h2-cnn-mlp, 0.7425)と比べたとき、前段を同じにしたまま 後段だけ MLP → DLGN に差し替えて +4.39pt というのがこの系列の主張であり、 「ネットワーク全体が論理ゲートである文献とゲート数を横並びにできない」理由でもある。

11. FPGAゲート予算・電力(Web調査)

Section titled “11. FPGAゲート予算・電力(Web調査)”

何を試したか: 上記の実験結果を FPGA に載せる前提で、 ゲート予算・パッキング・電力の相場を文献調査でまとめた(実測ではない)。

論点結論
CNN 前段を FPGA に載せられるか載る。hls4ml(7bit QAT)で同規模 conv 前段が 5.2µs / 約19.4万img/s / VU9P で LUT 12.8%・DSP 2.5%。PCIe 往復が消える(第1優先)
CNN を DLGN 化できるかできるが 100万ゲートでは CIFAR-10 ≈65%(LogicTreeNet 内挿)。MNIST 級は 566Kゲートで99.23% = 予算内
予算効率の最善手6-LUT ニューロン化。100万2入力ゲート ≈ LUT6 換算43万個で、FPGN-6-L が 434k LUT で CIFAR-10 76.72%(2入力比 +12pt)
100万ゲートは物理的に載るか空間展開で推定33〜50万LUT → VU9P級(1.18M LUT)なら折り畳み不要。fold が要るのはエッジ配備時だけ
conv 段の foldほぼ無償(真理値表が空間位置で共有済み。16Mゲートでもユニークは16kゲート ≈ 5,500 LUT。fold=H·W=1024、200MHz で約19.5万img/s)
FC 段の fold「層をまたいだ配線パターンの共有(butterfly化)」が成立条件。ランダム配線のままだと命令メモリ 44Mbit の壁で破綻
ランダム配線の実装コストpost-P&R で HPWL 3.5倍・Fmax 298MHz 止まり(構造化配線なら 526MHz)= 実装周波数を 0.57倍にする
トレードオフ式T·G ≤ f_clk · p · L / r(T=サンプル/s、G=ゲート数、p=パッキング率[gate/LUT]、L=LUT数、r=fold オーバヘッド)

文献側の相場として、LogicTreeNet(2入力ゲート)は 0.40M(S) 60.4% / 1.0M(内挿) ≈64〜66% / 3.08M(M) 71.0% / 16M(B) 80.2% / 61M(G) 86.3%。必須テクは residual init(なしで −9%)・ or-pooling(なしで −3.5%)・カーネル入力2ch制限 + k/8 グループ分割(配線輻輳回避)。 第1層は thermometer 符号化(R=8, 96ch)一択である(8bit 第1層は LUT 6.2倍・DSP 96倍・ レイテンシ33倍。thermometer なら精度劣化 0.0pt)。

優先順位: ①conv 前段の FPGA 同居(PCIe 消滅・3桁のレイテンシ改善)> ②conv-DLGN の位置 fold > ③6-LUT 化。 限界: パッキング率 p は推定値であり、export/ の Verilog を Vivado 合成して実測するまで すべての面積見積もりは仮である。

一族の中での現在地: CIFAR の精度×ゲート数は LogicTreeNet の対数直線 (10倍ゲートあたり +11.9pt)が基準線で、difflogic も結線学習系も外挿比 +2.9pt 程度= まだ誰も桁で線を破っていない。線を動かせたと確認できているのは 6-LUT 化だけである。 逆に二値/量子化 CNN は同じ精度をゲート換算で 29〜56倍多く使っており、 ゲート効率に限れば論理ネット側が明確に有利。 速度は ns級(全空間展開・II=1)と µs級(folding / 量子化CNN / GPU)の2クラスタに割れ、 間の 10²〜10⁴ ns はほぼ空白である。 そして我々のハイブリッド/市松は土俵が違う — 横軸に載るのは後段 DLGN 部だけで、 実数 NN 前段が残る限り ns 級クラスタには原理的に入れない。 純ゲート勢との正面比較が成立するのは「conv 段の DLGN 化 + 6-LUT 化」で基準線に乗ってからである。
