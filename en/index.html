Griffith

Build fast, low-power AI chips in Python

Train logic-gate networks and deploy them straight to FPGAs

QuickstartGitHub
TutorialsAPI reference

Named after Griffith Observatory, whose mission is to bring astronomy to everyone — we want differentiable logic to be just as accessible.

Make logic gates learnable

Train with a continuous relaxation, infer as a pure Boolean circuit. An IR (intermediate representation) bridges the two.

◧

Learnable logic gates

N-input LUTs (N=2/4/6) relaxed into differentiable form — from difflogic’s 16 gates all the way to FPGA LUT6, in one layer type.

⌁

Straight to FPGA

Extract the trained model into an IR (JSON), then emit Verilog / VHDL. Inference runs as bitwise operations — fast and low power, no GPU.

⇄

Hybrid networks

Keep attention in PyTorch and swap only the MLP for LUTs. Drop a logic layer into any existing nn.Module.

▤

Visual editor

Inspect the IR graph, LUT heatmaps and live training (time machine / gradient streaming) from the browser.

≡

HDL equivalence checking

Tests assert that PyTorch hard eval ⇔ IR simulate ⇔ HDL simulation all agree.

∇

Pluggable learning rules

BP / AP (derivative-free) / DFA / EGGROLL (evolution strategies), annotated per layer. Mix different rules in one network.
