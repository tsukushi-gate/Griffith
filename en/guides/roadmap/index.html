Learning Roadmap (Where to Start)

This site has more than 80 pages. You do not need to read them in order. The shortest path depends on where you are coming from, so use this page to decide where to start and what to read next — nothing else.

Decide in three seconds

  • New to machine learning → AI Basics
  • You can write PyTorch → Coming from PyTorch
  • Circuits / FPGA background → Appendix: XOR Internals
  • Researcher, want numbers → Benchmarks

The introductory course is a set of three

Steps 2-4 form one course — PyTorch basics → a small MLP → the same problem as a DLGN — and each runs in a few minutes on CPU. If you would rather just read, AI Basics and From NN to DLGN are enough to move on.

The naming is not accidental

In logic-gate networks the parts of the original architecture map directly onto Boolean operations — an LSTM forget gate literally becomes a 2:1 multiplexer. The tutorial titles foreground that discovery, which pulls them away from the generic names, but the content is a straightforward RNN / CNN / Transformer as the table above shows.
