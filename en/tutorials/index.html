Tutorials

Every page here was produced by actually running examples/*.py (all 27 of them, each running to completion on CPU alone). The figures, numbers and generated text are exactly those run results.

Each page ends with a “What to read next” section, so you can wander across the groups. To run them locally, the unexecuted notebooks in notebooks/ have the same content.
